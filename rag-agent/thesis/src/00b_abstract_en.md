# ABSTRACT

Question answering over the documents of companies and institutions increasingly relies on large language models (LLMs) combined with retrieval-augmented generation (RAG). RAG splits documents into fixed-length chunks, indexes them, and passes the chunks most similar to a question to the LLM. Documents such as financial reports, however, contain several hierarchical tables whose row and column headers span multiple levels, and chunking such a table separates the cell values below a chunk boundary from the headers that define their meaning. Once a value is separated from its headers, the retriever has difficulty finding the cells a question refers to, and the LLM cannot tell what a retrieved value stands for. This thesis therefore proposes cell-sentence RAG, which converts every data cell of a document into a sentence containing the table caption, the row header path, the column header path, and the cell value, and uses these cell sentences as retrieval units. The proposed method indexes the cell sentences with a public embedding model and, for each question, passes the top 20 cell sentences ranked by hybrid similarity to the LLM. Neither the embedding model nor the LLM is trained, and the entire pipeline runs locally without external APIs. Experiments on 882 MultiHiertt questions, sampled with at most 300 questions per question group, show that removing the header paths from the indexed cell sentences lowers answer accuracy from 46.3% to 16.2%, and that the proposed method achieves significantly higher answer accuracy than LangChain chunking, RAPTOR, and TableRAG (Chen) run with the same LLM; it also scores higher than TableRAG (Yu), but that difference is not significant. The proposed method also reaches higher answer accuracy than feeding all tables of the document while using less than half of the input tokens.
