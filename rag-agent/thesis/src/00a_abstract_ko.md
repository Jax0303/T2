# 국문 초록

계층형 표는 셀 값의 의미가 여러 층의 행·열 머리글 조합으로 정해진다. 표를 평평하게 펴거나 행·청크 단위로 잘라 검색하면 셀과 머리글이 분리되어, 검색기와 리더 모두 셀 값이 무엇의 값인지 알기 어렵다. 본 연구는 외부 API 없이 로컬 모델만 쓰는 폐쇄된 환경에서, 셀마다 행 머리글 경로·열 머리글 경로·값을 담은 문장을 만들고 이를 학습하지 않은 기성 임베딩 모델로 색인해 셀을 검색한다. 셀을 머리글 경로와 함께 문장으로 만드는 표현은 MT2Net(Zhao et al., 2022)이 먼저 썼다. 본 연구는 검색기를 학습하지 않고, 같은 문서 안에서 문장이 같아지는 셀을 구별하도록 경로를 늘리며, 표·행·청크 단위 색인과 같은 조건에서 통계 검정으로 비교한다.

MultiHiertt에서 TableRAG 셀 검색 재구현과 그 논문의 비교군(RowCol, RandRow), 이종 문서용 청크, 고정 길이 청크를 같은 임베딩 모델·검색기·전달 셀 수(상위 20개 셀)로 비교했다. 셀 단위 검색은 정답 셀 포함률이 이 비교군들보다 높았다(문서 안 .8634, 표 5-1). 셀 문장에 잎 라벨을 한 번 더 붙인 변형(sleaf)은 본 방법보다 높았다(.8728). 머리글 규칙을 맞춘 비교에서 답변 정확도는 고정 청크보다 높았고(408 대 368/882, p=.0052), 두 방법 모두 정답 셀 전부를 리더 입력에 포함한 문항에서는 차이가 없어(59:62, p=.86) 답변 차이는 한쪽 방법만 정답 셀 전부를 리더 입력에 포함한 문항에서 나왔다. 검색 없이 문서의 표 전체를 넣은 조건과는 유의한 차이가 없었다(408 대 378, Holm p=.078).
