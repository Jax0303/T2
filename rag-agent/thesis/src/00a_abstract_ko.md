# 국문 초록

계층형 표는 셀 값의 의미가 여러 층의 행·열 머리글 조합으로 정해진다. 표를 평평하게 펴거나 행·청크 단위로 잘라 검색하면 셀과 머리글이 분리되어, 검색기와 리더 모두 셀 값이 무엇의 값인지 알기 어렵다. 본 연구는 외부 API 없이 로컬 모델만 쓰는 폐쇄된 환경에서, 셀마다 고유 라벨·행 머리글 경로·열 머리글 경로·값을 담은 문장을 만들고 이를 학습하지 않은 기성 임베딩 모델로 색인해 셀을 검색한다. 셀을 머리글 경로와 함께 문장으로 만드는 표현은 MT2Net(Zhao et al., 2022)이 먼저 썼다. 본 연구는 검색기를 학습하지 않고, 셀 문장에 표 제목 라벨을 붙이며, 표·행·청크 단위 색인과 같은 조건에서 통계 검정으로 비교한다.

HiTab과 MultiHiertt에서 TableRAG 셀 검색 재구현과 그 논문의 비교군(RowCol, RandRow), 이종 문서용 청크, 고정 길이 청크를 같은 임베딩 모델·검색기·셀 예산 규칙(20셀)으로 비교했다. 셀 단위 검색은 두 데이터셋에서 정답 셀 포함률이 이 비교군들보다 높았다(HiTab 538개 표를 한 색인에 넣은 조건 .9142(표 5-3), MultiHiertt .8634). HiTab에서 데이터셋이 준 표 제목을 라벨로 넣으면 검색 정확도가 유의하게 올랐으며, 문장 틀 자체는 효과가 없었다. 머리글 규칙을 맞춘 비교에서 답변 정확도는 고정 청크보다 높았고(HiTab 237 대 206/300(템플릿은 같은 표본의 결과를 보고 선택, Holm p=.0019), MultiHiertt 408 대 368/882(p=.0052)), 두 방법 모두 정답 셀 전부를 문맥에 포함한 문항에서는 차이가 없어(HiTab 29:20 p=.25, MultiHiertt 59:62 p=.86) 답변 차이는 한쪽 방법만 정답 셀 전부를 문맥에 포함한 문항에서 나왔다. 표 전체 입력과는 유의한 차이가 없었다.

주제어: 계층형 표, 표 질의응답, 검색 증강 생성, 셀 검색, 머리글 경로
