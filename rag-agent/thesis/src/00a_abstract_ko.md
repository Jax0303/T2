# 국문초록

최근 기업과 기관이 보유한 문서에 대한 질의응답에 대규모 언어 모델(LLM)과 검색 증강 생성(RAG)을 도입하는 사례가 늘고 있다. RAG는 문서를 일정한 길이의 청크로 잘라 색인하고, 질문과 유사한 청크를 찾아 LLM의 입력으로 전달한다. 그러나 재무 보고서와 같은 문서에는 행 머리글과 열 머리글이 여러 층으로 이루어진 계층형 표가 여러 개 들어 있으며, 이러한 표를 청크로 자르면 청크 경계 아래의 셀 값이 그 값의 의미를 정하는 머리글과 분리된다. 셀 값과 머리글이 분리되면 검색기는 질문이 가리키는 셀을 찾기 어렵고, LLM은 검색된 값이 무엇의 값인지 알 수 없다. 따라서 본 학위논문에서는 문서의 각 데이터 셀을 표의 캡션, 행 머리글 경로, 열 머리글 경로, 셀 값을 담은 하나의 문장으로 변환하고, 이 셀 문장을 검색 단위로 사용하는 셀 문장 기반 검색 증강 생성 방법을 제안한다. 제안하는 방법은 셀 문장을 공개 임베딩 모델로 색인하고, 질문이 주어지면 하이브리드 유사도로 상위 20개 셀 문장을 찾아 LLM에 전달한다. 임베딩 모델과 LLM은 학습하지 않으며, 모든 과정은 외부 API 없이 로컬 환경에서 수행한다. MultiHiertt 데이터셋에서 문항 그룹별로 최대 300문항씩 뽑은 882문항으로 실험한 결과, 셀 문장의 색인에서 머리글 경로를 제거하면 답변 정확도가 46.3%에서 16.2%로 떨어졌으며, 제안하는 방법은 같은 LLM을 사용한 LangChain 청크 분할, RAPTOR, TableRAG(Chen)보다 유의하게 높은 답변 정확도를 보였고, TableRAG(Yu)보다는 높았으나 그 차이는 유의하지 않았다. 또한 문서의 표 전체를 입력하는 경우의 절반 이하의 입력 토큰으로 더 높은 답변 정확도를 얻는 것을 확인한다.
