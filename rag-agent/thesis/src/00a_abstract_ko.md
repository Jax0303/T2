# 국문 초록

계층형 표는 셀 값의 의미가 여러 층의 행·열 머리글 조합으로 정해진다. 표를 평평하게 펴거나 행·청크 단위로 잘라 검색하면 셀과 머리글이 분리되어, 검색기와 리더 모두 셀 값이 무엇의 값인지 알기 어렵다. 본 연구는 외부 API 없이 로컬 모델만 쓰는 폐쇄된 환경에서, 셀마다 고유 라벨·행 머리글 경로·열 머리글 경로·값을 담은 문장을 만들고 이를 학습하지 않은 기성 임베딩 모델로 색인하는 셀 검색 방법을 제안한다.

HiTab과 MultiHiertt에서 TableRAG의 표현들, 이종 문서용 청크, 고정 길이 청크와 같은 임베딩 모델·검색기·셀 예산(20셀)으로 비교했다. 본 방법의 검색 정확도는 HiTab 단일 셀 조회 .9586, MultiHiertt 전체 .8638로 모든 비교군보다 높았다(HiTab 산술은 고정 청크와 동률). HiTab에서 데이터셋이 준 표 제목을 라벨로 넣으면 검색 정확도가 유의하게 올랐으며, 문장 틀 자체는 효과가 없었다. MultiHiertt에서는 머리글 추정이 한 층을 놓쳐 셀 문장이 서로 같아진 문항에서 리더가 값을 구별하지 못했고, 머리글 규칙을 고치자 회복되었다. 답변 정확도는 두 데이터셋 모두 검색 방법 중 본 방법이 가장 높았으나(HiTab .7500, MultiHiertt 가중 .3375), 표 전체를 넣는 조건과는 유의한 차이가 없었다.

주제어: 계층형 표, 표 질의응답, 검색 증강 생성, 셀 검색, 머리글 경로
