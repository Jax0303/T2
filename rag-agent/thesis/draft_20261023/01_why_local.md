# 1장 삽입 문단 초안 — "왜 로컬 LLM 인가" (2026-10-23; 찐최종.hwpx 1.1 절 끝 문장 교체)

## 바꿀 자리
1.1 절 마지막 문단(section2#9)의 마지막 문장 "그리고 보안상 문서를 외부 서비스로 전송할 수 없는 기관에서는 외부 API 없이 로컬 환경의 공개 모델만으로 동작하는 구성이 필요하다." 를 지우고, 아래 문단을 새 문단으로 넣는다. 참고문헌 [24]~[27] 추가.

## 문단
검색 증강 생성은 검색된 문서 조각을 그대로 언어 모델의 입력으로 넘기므로, 외부 API 모델을 사용하면 문서 내용이 외부 서버로 전송된다. 본 논문의 평가 집합(882문항, 문서 582개)에서 이 양을 재면, 문서의 표 전체를 입력하는 방식은 표 2,344개가 통째로 전송되고, 검색 단위를 셀로 줄인 제안하는 방법도 질문당 문서 셀의 평균 32%가 전송되며 같은 문서에 질문이 반복되면 절반에 가까운 셀이 누적 전송된다(4.4절). 기업과 기관의 내부 문서는 이러한 전송 자체가 제한된다. 삼성전자는 2023년 3월 사내 ChatGPT 사용을 허용한 지 20일 안에 반도체 설비 소스코드가 입력되는 사고를 겪었고 같은 해 5월 사내 생성형 AI 사용을 금지하였으며[24], 금융권은 망분리 규제 아래 생성형 AI를 보안 대책을 조건으로 한 규제 샌드박스 특례로만 허용하고[25], 공공기관 보안 지침은 개인정보를 포함한 기관 내 민감 정보의 입력을 지양하도록 한다[26]. 전송된 입력은 공급자 정책상 남용 감시 목적으로 최대 30일 보존되고 법적 요구가 있으면 더 오래 보존될 수 있다[27]. 또한 외부 모델은 제공되는 모델 버전이 공급자에 의해 교체·종료되고, 같은 입력에 대한 출력의 재현을 보장하지 않는다(4.4절). 따라서 본 논문은 외부 API 없이 로컬 환경의 공개 모델만으로 동작하는 구성을 전제로 하고, 같은 입력과 같은 지시문에서 외부 모델과의 답변 정확도 차이를 4.4절에서 함께 보고한다.
