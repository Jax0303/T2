## 연구 질문 (이 실험이 답하는 것)

**질문이 속한 문서의 표들(평균 4.06개, 계층 머리글) 안에서 답에 필요한 셀 근거를 찾는 검색**에서, 같은 검색기·같은 필터·같은 리더를 두고
**셀 텍스트 표현만 바꿨을 때** 검색·필터 후 근거·답변이 어떻게 달라지는가. 전체 시스템 비교가 아니다(원 논문 시스템은 재현하지 않음, 4.2절).
평가 집합은 표 근거만 필요한 문항이며(본문 근거가 필요한 4,922건 제외), 이 결과를 "MultiHiertt 전체 성능"이라 부르지 않는다.
답변 평가 표본 882건은 처음 규칙 시절부터 쓴 고정 표본이고 머리글 규칙·고유화가 이 표본을 보고 고쳐졌다(6.5절) — 독립 test 가 아니다.

## 지표

- **A 필터 전**: `results/fair_mh_20260928/retrieval_metrics.py` — Recall/Precision/F1/Hit/All-Evidence@1,5,10,20, 질문별 → macro. 좌표 기준 중복 제거.
  셀 순위 k 와 단위 순위 k 를 따로 낸다(청크·표·행 arm 은 단위 하나에 셀 여러 개). 기존 "correct" = All-Evidence@예산20.
- **B 필터 후**: 선택 셀 집합의 Recall·Precision(분모 = 실제 선택 셀 수)·F1, 전체 근거 보존율, 평균 선택 셀 수, 빈 선택 수, 잘못된 번호 수,
  제거된 정답 셀 수와 제거된 비정답 셀 수. 청크 arm 은 줄↔셀 대응이 없어 정답 셀 **값 문자열 잔존**(대리 지표)만 낸다고 표기한다.
- **C 답변**: `rag_agent/eval/multihiertt_em.mh_exact_match`(공식 포팅). 필터 없음 값은 기존 882 결과(표 5-8, 같은 리더 설정)를 쓴다.
- 진단: 정답 셀만 준 조건(`--condition gold`, 882, 채택 리더 설정). 검색 성능과 분리해 보고.

## 필터 규칙 (실행 전 고정)

Qwen3-8B 4bit 비생각, greedy, 최대 64토큰, continuous batching 128. 프롬프트 = `mh_filter.FILTER_SYS`(산술·비교는 피연산자 전부 포함 지시).
입력 = 질문 + 번호 붙인 줄(셀 arm: 줄 = 셀 문장; 청크 arm: 줄 = 표의 행). 출력 = 번호. 범위 밖 번호는 버리고 센다. 숫자가 없으면
문맥 **빈 목록**(자동 대체 없음), 센다. 답변 모델에는 선택된 줄의 원문만 간다. 정답 정보는 필터 입력에 없다.
