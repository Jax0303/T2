## 규칙 v3 = v2 + S1~S6 (MultiHiertt HTML 에만)

- **S1 병합 표기는 열 범위를 정한다.** 헤더 행에 병합 표기(colspan/rowspan)가 하나라도 있으면 그 행은
  표기를 믿는다: 병합이 덮는 자리는 원점 글을 받고, 자기 `<td>` 가 있는 빈 칸은 병합이 아니므로
  왼쪽 라벨을 물려받지 않는다. 표기가 없는 행과 `<td>` 가 모자라 채운 자리는 v2 추정 그대로다.
- **S2 빈 행 표제는 물려받지 않는다.** 데이터가 있는 행의 마지막 표제 칸이 자기 `<td>` 로 비어 있고
  rowspan 에 덮이지 않았으면 앞 행 표제를 잇지 않는다.
- **S3 라벨 행은 헤더다.** 모서리가 빈 표의 헤더 탐색에서, 표제 칸에 글이 있어도 데이터 영역의 채워진
  칸이 두 개 이상이고 그중 데이터 모양(숫자·결측 표시)이 하나도 없으면 헤더 블록을 잇는다.
  (v2 의 연도 행 규칙을 각주 붙은 연도·날짜·텍스트 라벨로 넓힌 것.)
- **S4 합계 행은 자기 구획을 닫는다.** 표제가 `Total`/`Subtotal` 로 시작하는 데이터 행 **다음** 행부터
  가장 안쪽 구획 표제를 떼어 낸다. 표 머리의 지속 범위(선두 표제 연속의 바깥 단계)는 떼지 않는다.
- **S5 같은 경로는 원표의 구획 표제로 가른다.** 같은 표에서 데이터 행의 행 경로가 같으면, 각 행 위에
  실제로 있던 구획 표제 중 경로에 없는 가장 가까운 것부터, 행끼리 달라질 때까지만 붙인다(원표 순서 유지).
  붙여도 갈리지 않으면 붙이지 않는다.
- **S6 모서리 칸의 시점은 표 전체의 시점이다.** 모서리 블록(헤더 행 × 표제 열)에 네 자리 연도가 있고
  어떤 열 경로에도 연도가 없으면, 모서리 글을 모든 열 경로 맨 앞에 붙인다.

## 규칙으로 고칠 수 없는 것

**표 구분 실패.** 두 표의 헤더 블록(모서리 포함)이 같으면 격자 안에는 두 표를 가를 글이 없다.
구별 정보는 표 밖 문단(L1/L2)에 있고, 라벨 규칙은 이 등록에서 바꾸지 않는다. 표 번호 같은 인위적
식별자는 `CLAUDE.md` §1 에 따라 라벨이 아니다. 리더 문맥에서 표 경계를 표시하는 방안은 문장이 아니라
프롬프트 변경이므로 이 등록 범위 밖이며 따로 결정한다.

## 측정 (모델 실행 없음 — 인코더·리더 둘 다 돌리지 않는다)

`analysis/header_v3_impact.py` → `results/mh_header_v3/`. train 전체 표에서 v2 와 v3 를 비교한다.

7. **interim200.** gold 셀 문장이 바뀐 질의 수, 문서 안 문장이 하나라도 바뀐 질의 수.
8. **표 구분 실패 규모.** 표 사이 충돌 중 두 표의 헤더 블록이 같은 비율.
9. 결함 사례 8건의 해당 문장 v2 → v3.

## 채택 기준

규칙마다 v2 + 그 규칙 하나로 잰다. **M2 또는 M3 를 0.5pt 넘게 떨어뜨리거나 `gold_in_header` 를
늘리는 규칙은 v3 에서 뺀다.** 뺀 규칙이 있으면 v3 정의를 고치고 그 사실과 수치를 이 문서 아래에 덧붙인다.

## 범위와 순서

### v3.1 = v2 + S1n~S6n

- **S1n** 병합 범위를 **선언한** 라벨(colspan/rowspan 칸)만 선언 범위 밖에서 끊는다. 1×1 라벨과, 병합이

## 정정 2 — S1n 구현 결함, 재측정 전 (2026-09-14)
