# 사전등록 2026-10-21 — 셀 고르기 단계(줄 단위 선택, 같은 LLM) dev 395 × 세 입력 × 2회

## 왜
- 600 상한 진단(PREREG-2026-10-21-ceiling-600.md): 정답 셀만 475 대 잘라낸 표 399.7(+75, 12.5%p), 그중 표 안 잡음 몫 56. 10-07 잡음 사다리: 손실은 잡음 유무에서 생기고 양에 둔감 → T 축소·표 수 제한으로는 회복 안 됨(표 수 제한은 10-18 닫힘). 정답 셀에 가깝게 고르는 단계가 필요.
- 사용자(10-21): "노이즈 안 낄 정도로 표본 수 맞춰서 빠르게" → 기대 효과 5%p 이상이면 dev 395 × 2회로 충분(엇갈림 15% 가정, 80% 검정력 ≈ 470문항; 2회로 보강). 3%p 효과는 이 설계로 못 잡음을 미리 적음.
- 공정성: 세 입력 모두 같은 고르기 지시문·같은 LLM·같은 규칙(9-21 공정 필터 설계: 줄 단위 압축, 유닛 고르기 아님). 선택 단계는 정답 정보를 보지 않는다. 답변 단계는 지금 지시문 P* 그대로. 토큰 상한 T 는 같고 적게 주는 것은 허용.

## 고정 조건
- 문항 dev 395(선택용; 평가 문항 882·600 안 봄). 기준 = `results/sentence_dev_20261019/run1,run2` 의 A·D·Cp(P*, 4,096, 동시 32/20).
- 고르기 단계 `scripts/select_lines.py`: context 를 빈 줄 제외 물리 줄로 쪼개 "1: …" 번호 → Qwen3.5-4B(vLLM, 비생각, temperature 0, 최대 512 토큰) → 번호만 받음 → 그 줄 원문만 남김. 지시문(원문 불변)은 스크립트 INSTR. 구조 줄 규칙(마크다운 표 입력 A·D 에 같게): 어떤 표 블록의 값 줄을 하나라도 남기면 제목 줄("Table N")·머리글 줄(블록 첫 줄)·구분 줄도 남김. 셀 문장 목록(Cp)은 줄마다 자립하므로 해당 없음. 번호 0개면 빈 문맥(자동 대체 없음). 입력 밖 번호는 버리고 셈.
- 답변 단계: `prompt_sweep.py` P* R1X1F1B2D1C1E0, 4,096, 2회(동시 32/20) → `results/select_dev_20261021/run{1,2}/{AF,DF,CpF}`. 채점 `score_formats2.py`(마지막 줄 포함 v2), 비교 `compare.py`(있음 대 없음 같은 실행 번호끼리 McNemar, 2회 평균, 고르기 통계·셀 문장 목록 정답 셀 줄 유지율).

## 판정 규칙(결과 전 고정)
- **채택(잘라낸 표)**: DF − D 2회 평균 ≥ +16(4%p) 이고 두 실행 모두 p<.05 → 새 문항 600 에서 3회 확인(별도 사전등록).
- 셀 문장 목록(CpF − Cp)·LangChain 청크(AF − A)도 같은 규칙으로 따로 판정해 적는다(어느 입력이든 채택이면 600 확인에 포함).
- **효과 없음**: 2회 평균 ±10 안 → 노선 닫음. **해침**: −16 이하이고 두 실행 모두 p<.05 → 닫고 원인(빈 문맥·정답 줄 손실) 수치를 적음. 그 밖(혼합)은 수치 그대로, 결정은 사용자.
- 고르기 있음 아래 입력 간 비교는 참고로만 적는다(주 비교 아님).
