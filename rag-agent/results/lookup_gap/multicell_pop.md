즉 유형 B는 지금 채점기로 그대로 된다. 유형 A는 답이 한 개라 답변 채점은 단일 gold와

## 실행 전에 정해야 할 것

1. **구분자.** `em()`의 다중 gold 경로는 예측을 **콤마로만** 자른다. 측정:

   | 모델 출력 | 채점 |
   |---|---|
   | `13.8, 14.9` | 1 |
   | `14.9, 13.8` | 1 (순서 무관) |
   | `13.80, 14.90` | 1 |
   | `13.8,14.9` | 1 |
   | `13.8 and 14.9` | **0** |
   | `13.8 14.9` | **0** |
   | `13.8, 14.9, 15.0` | 0 (여분) |
   | `13.8` | 0 (누락) |

   콤마 구분을 프롬프트로 강제하거나, 구분자 규칙을 사전등록에서 넓히거나 —
   둘 중 하나를 **정하고 나서** 돌려야 한다.

2. **유형 A를 포함할지.** 조건 셀이 gold에 들어 있어 검색은 다중 셀이지만 답은 한 개다.
   포함하면 "다중 조회"의 정의가 검색 기준이 되고, 빼면 34건만 남는다.

3. 관측 하나: `em("The answer is 13.8, 14.9", "['13.8','14.9']")` = 1이다.
   콤마 조각 안에 숫자가 하나뿐이면 R1(상대오차)이 산문을 통과시킨다.
