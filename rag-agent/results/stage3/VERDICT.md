## 판정

0. **단일 셀 test 답변 레그(이월 항목)를 처음 쟀다.** `gold` .8895 / `top10` .6970 / `top3` .6996
   / `top1` .6424 / `orc10` .8505. 검색 재현: `top1` 의 gold 주입률 .6710 = test R@1, `top10` 의 gold
   전부 주입률 .9246 = test all-covered@10 (`results/p0_confirm/`) — 소수점까지 같다.
   dev 에서 본 세 가지가 test 에서 그대로 선다: (a) 재정렬 자리의 몫 `orc10` vs `top10` = **145:27,
   p=1.0e-20, +.1535** (dev +.1494); (b) `top3` ≈ `top10` = 52:50, p=.92 (dev 48:52, p=.76), 토큰 226 vs 627;
   (c) `gold` vs `orc10` = 34:4, p=6.0e-07 — top10 밖 7.5% 가 그대로 비용이다.
   예측 셋(gold .89, top10 .70, top3 .69)이 전부 구간 안이다.

1. **다중 셀 조회의 `gold` 는 `results/multicell/CEILING.md`(2026-09-01)와 소수점까지 같다**
   (.7879 / .9032). 같은 프롬프트·같은 리더의 재실행이 결정적임을 다시 확인한 것이다.
2. **다중 셀은 셀을 다 넣어도 리더가 .79/.90 이고, 검색 상위 10개를 넣으면 .45/.58 이다.**
   gold 가 전부 들어온 질의만 봐도 .56/.69 — **distractor 비용이 단일 셀(−.16)보다 크다**
   (다중 dev: `gold` .7879 vs `top10`|주입됨 .5556 = −.23). `orc10` .67/.77 이 상한이다 (n=33/31, 참고치).
3. **산술은 리더가 천장이다.** 정답 셀만 넣어도 dev **.3714** / test **.5464**. 검색 top-10 은
   .1429 / .2077 이고, gold 가 전부 들어온 질의로 좁혀도 .2581 / .2879 다. `orc20` 이 `gold` 에
   거의 닿는다(dev .3543 vs .3714, test .5191 vs .5464) — **K=20 이면 검색은 셀을 이미 갖고
   있고**, 못 하는 것은 (a) 그 20개 중 고르기, (b) 고른 뒤 계산하기다.
4. **"셀이 하나라도 빠지면 오답"은 성립한다 — 예외 ≤ 4% 이고 전부 설명된다.** `EM|안됨` 이
   0 이 아닌 건은 (i) m=12 평균 질의(정답 71.05)를 70.9 로 답해 채점기 R1 규칙(상대오차 <1%)으로
   통과, (ii) `opposite` 집계(gold 셀 −23.8, 정답 23.8)에서 부호 없는 같은 값을 다른 셀에서 읽음,
   (iii) 차이 질의 1건이 우연히 일치. 산술 dev `top10` 에서 1/175 다.
5. **`top3` ≈ `top10` 이 다중·산술에서도 재현된다.** 다중 test 2:9 (p=.065), 산술 dev 8:6 (p=.79),
   산술 test 12:11 (p=1.0). 토큰은 2.7~2.8배 적다. `rerank/VERDICT.md` 의 단일 셀 관측
   (48:52, p=.76)과 같은 방향. **사후 관측이다. 채택하려면 별도 사전등록.**
6. **`top20` 은 산술에서도 `top10` 과 구별되지 않는다** (dev 3:6 p=.51, test 15:10 p=.42) —
   gold 전부 주입률은 .53→.63 / .72→.86 으로 오르는데 EM|주입됨이 .26→.20 / .29→.27 로
   내려가 상쇄된다. `VERDICT_ORC.md` 의 "`topK` 축의 distractor 비용" 그대로다.

## 단서

- 다중 셀 n=33/31 은 참고치다. 짝지은 검정의 b+c 가 10 안팎이라 검정력이 없다.
- 산술 test 의 리더 천장(.5464)이 dev(.3714)보다 높다. 두 스플릿은 독립 표본이고 표 크기도
  다르다(gold 표 중앙 90 vs 130 셀) — 원인으로 세우지 않는다.
- 산술은 리더 1종(Qwen2.5-7B-Instruct 4-bit)이다. `RESULTS.md` §10 의 Coder/extract 레그(Task C)는
  여전히 미실행이고, 이 사다리가 그 레그를 대체하지 않는다.
- R1 채점 규칙(상대오차 <1%)이 m 큰 평균 질의에서 근사값을 통과시킨다 (판정 4-i). 산술 EM 을
  인용할 때 그 규칙을 같이 적을 것 (`PREREGISTER.md` 개정 5).
