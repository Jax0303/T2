# 왜 로컬 LLM 인가 — 근거 노트 (2026-10-22, 지도교수 지시 1 대응; 원고 반영은 보류 상태의 초안)

지도교수 지시(사용자 정정): "기업이니까 로컬 LLM 을 써야 한다 — 왜? 증명해라." 지금 원고(`thesis/찐최종.hwpx`)에는 "보안상 문서를 외부 서비스로 전송할 수 없는 기관에서는 외부 API 없이 로컬 환경의 공개 모델만으로 동작하는 구성이 필요하다" 한 문장만 있고 근거·인용이 없다.

## 1. 증명할 수 있는 것과 전제인 것
- "기관은 문서를 외부로 보낼 수 없다"는 문제 정의의 **전제**이고 실험으로 증명되는 명제가 아니다.
- 증명(제시) 가능한 것 셋: (a) RAG 구조상 외부 LLM 사용 = 검색된 문서 내용의 외부 전송이며, 그 양을 우리 파이프라인에서 잴 수 있다. (b) 외부 서비스에 의존했을 때 실제로 일어난 일(우리 로그). (c) 전송을 금지·제한하는 규정과 사고 사례(인용).
- 여기에 "로컬의 대가"(같은 입력·같은 지시문에서 외부 대 로컬 정확도 격차)를 함께 적어야 논의가 닫힌다 → `PREREG-2026-10-22-reader-sweep.md` 결과 뒤.

## 2. (a) 외부로 나가는 양 — 10-13 GPT-4o 실행 로그·입력 레코드에서 계산 (2026-10-22, 새 실행 없음)
- 평가 문항 882 = 고유 문서 582(문서당 문항 최대 5), 표 2,344개, 값 셀 83,778개(`doc_text` 기준).
- 토큰은 OpenAI 응답 `usage.prompt_tokens` 합(10-13 실제 전송량). 셀 비율은 문항마다 `cells_in_context / 문서 셀 수`.

- 10-13 실행 4조건 합계: 프롬프트 3,105,614 토큰 + 출력 118,156 토큰(사전 추정 370만의 84%). 표 전부 조건에서는 582개 문서의 표 2,344개가 전부 외부 서버에 도달했다.
- 같은 문서에 문항이 여럿이면 본 방법 C 의 누적 전송은 문서 셀의 평균 ≤ 47.6%, 37/582 문서는 상한 100%(셀 id 없이 센 상한, 합집합은 이보다 작을 수 있음).
- 읽는 법: 검색 단위를 셀로 줄여도 질문당 문서의 약 1/3 이 나가고, 누적하면 절반에 가깝다. 전송을 거의 피하는 입력은 "정답 셀만"(2.1%)뿐인데 그것은 정답을 아는 상한 조건이다. 따라서 "외부 모델을 쓰되 적게 보낸다"는 선택지는 RAG 에 없다.

## 3. (b) 외부 서비스에서 실제로 일어난 일 — 우리 로그(`PREREG-2026-10-13-gpt4o.md`, `results/gpt4o_20261013/`)

- 가용성: 16:52 PC 재부팅(우리 쪽) 중단, 16:56 HTTP 429 `billing_not_active`(크레딧 소진)로 ①576·④505 문항에서 중단, 17:20 충전 뒤 재개.
- 종료·교체: GPT-4o 는 ChatGPT 에서 2026-02-13 퇴역(OpenAI 안내 "Retiring GPT-4o and other ChatGPT models", 2026-01-29 공지; **원문 403 으로 검색 요약·2차 보도로 확인**), API 의 `chatgpt-4o-latest` 는 2026-02-16 종료, 다른 GPT-4o 변종은 유지(VentureBeat 2025-11-21, 원문 열람). ## 5. 원고 1장 문단 초안 (보류; 인용 번호는 원고 참고문헌 체계에 맞춰 넣음)
검색 증강 생성은 검색된 문서 조각을 그대로 언어 모델의 입력으로 넘기므로, 외부 API 모델을 쓰면 문서 내용이 외부 서버로 전송된다. 본 연구의 평가 집합(882문항, 582개 문서)에서 이를 재면 표 전부를 넣는 방식은 문서의 표 2,344개가 통째로 나가고, 검색 단위를 셀로 줄인 본 방법도 질문당 문서 셀의 평균 32%가, 같은 문서에 질문이 반복되면 절반에 가까운 셀이 누적 전송된다. 기업·기관 문서는 이런 전송 자체가 제한된다. 삼성전자는 2023년 3월 사내 ChatGPT 허용 20일 안에 설비 소스코드가 입력되는 사고를 겪고 같은 해 5월 생성형 AI 사용을 금지했으며[ ], 금융권은 망분리 규제 아래 생성형 AI 를 샌드박스 특례와 보안 조건에서만 허용하고[금융위원회 2024], 공공기관 지침은 기관 내 민감 정보 입력을 지양하도록 한다[국가정보원 2023]. 전송된 데이터는 공급자 정책상 남용 감시 목적으로 최대 30일 보존되고 법적 요구가 있으면 더 오래 보존될 수 있으며[OpenAI], 2025년 미국 법원은 소송 증거 보존을 위해 삭제된 로그까지 보존하도록 명령했다[ ]. 외부 모델은 또 seed 가 없고 서빙 스냅샷이 공급자에 의해 교체·종료되어(GPT-4o 의 ChatGPT 퇴역, 2026년 2월) 같은 입력의 재현을 보장하지 않으며, 본 연구의 GPT-4o 실행도 크레딧 소진으로 한 차례 중단되었다. 따라서 본 연구는 외부 API 없이 로컬 환경의 공개 모델만으로 동작하는 구성을 전제로 하고, 같은 입력·같은 지시문에서 외부 모델과의 정확도 격차를 "로컬의 대가"로 5장에서 함께 보고한다.
