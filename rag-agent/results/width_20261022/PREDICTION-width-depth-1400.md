# 예측(분석 실행 전 기록, 2026-10-22)
가설: 셀 문장의 답변 단계 이득 = LLM 이 값을 행·열 머리글에 맞추는 일을 대신해 준 것. 그러면 표가 넓거나(열 많음) 머리글이 깊을수록(위쪽 머리글 줄 수), 정답이 표 2개 이상에 걸칠수록 잘라낸 표·목록 대 LangChain 격차가 커져야 한다.
예측: 4B 무양자화는 표를 잘 읽으므로(LangChain 조회 81%) 버킷 간 격차 차이가 ±2%p 안에서 평평할 확률 55%, 넓은/깊은 버킷에서 격차가 커질 확률 45%. 정답 표 2개+ 버킷에서 격차 커질 확률 50%.
판정: 버킷별 3회 평균 격차(D−A, C−A)가 좁은→넓은 순으로 단조 증가하고 끝 버킷 차이가 3%p 이상이면 "경향 있음", 아니면 "없음". 사후 분석이며 주장 근거가 아니라 다음 사전등록의 입력일 뿐.
