# 판정: 다섯 표현 재측정 완료

두 신규 arm 각각 전체 1,581문항의 답변 생성이 완료됐다. 주지표는 동일한 991문항이다. 생성 모델·프롬프트·채점 규칙을 결과에 맞춰 변경하지 않았다.

본 방법 검색 .9142 / EM .7074, 자체 청킹 .7659 / .6105, MT2Net 착안 .8153 / .5610, Huawei 착안 .6771 / .5257, RowCol leaf .5126 / .3290이다. 검색−EM 차이는 15.14~25.43pp이며 동일 채점 감사 후에도 남는다.

다섯 표현의 공통 검색 성공 321문항에서 EM은 본 방법 .8224, 자체 청킹 .8474, MT2Net 착안 .7445, Huawei 착안 .8224, RowCol leaf .6885다. 별도 RowCol 전체 경로 복원은 같은 집합에서 .8660이다. 따라서 본 방법의 전체 EM 우위가 모든 검색 성공 문항에서 더 잘 읽힌다는 뜻은 아니다.

RowCol 경로 손실의 영향은 같은 검색 셀을 고정한 진단으로 뒷받침된다. 다른 arm들의 제목·문맥 크기·임베딩 절단 차이는 확인했지만 각각의 인과적 기여량을 분리하지 않았다. 모든 격차 원인을 해결했다고 결론 내리지 않는다.

방어 가능한 범위: 공통 검색기·리더를 사용하는 표현 적응 실험으로서 출처, 모집단, 문맥, 동일 자동 채점을 검증했다. 원본 전체 시스템의 충실한 재현, 동등한 헤더 정보/토큰 예산 비교, 독립적인 인간 정답 감사까지 완료됐다는 주장은 불가하다.

검증: 매니페스트의 다섯 arm 전수 재채점, 파일·문맥 hash, 동일 query ID·gold 좌표·reader 조건 확인 통과. 기존 RowCol 경로 진단의 검색 셀 불변성 및 동일 생성 조건도 재검증했다. 평가 무결성/비교군 관련 회귀 테스트 56개 통과. 검수용 익명 목록은 준비했지만 사람 판정 미실시다.

재현: 저장소 rag-agent에서 .venv/bin/python analysis/five_representation_audit.py --repo . --out NEW_OUTPUT_DIRECTORY 실행. 기존 출력은 덮어쓰지 않는다. 생성 명령은 PREREG-2026-09-12-five-representations.md와 각 결과 JSON의 arguments, 실행 로그를 참조한다.

다음: 교수님께 전체 gap 표, 공통 hit 표, RowCol 경로 복원 진단을 함께 설명한다. MultiHiertt는 test 정답 비공개와 현 로컬 캐시/어댑터 제약을 먼저 해결해야 한다. train/validation 대체 실행이나 외부 제출은 하지 않았다.
