# 노이즈를 전부 없앴을 때 남는 오답 43건은 어디서 왔나 (2026-09-10)

조건: 문맥에 **gold 셀만** 넣는다(주지표 m=1 이므로 문장 한 줄). 리더
`Qwen2.5-7B-Instruct?quantization=4bit`, temperature 0. 991문항 중 948 정답 = 0.9566.

질문: **남은 43건은 순전히 환각인가?** 답: **아니다. 16건(37%)만 환각이다.**

판정 방법: 예측에 나온 숫자가 (a) gold 셀 값과 표기만 다른가, (b) 문맥 문장 안 다른
숫자인가(제목·헤더), (c) 셀 값의 결정적 변환인가, (d) 어디에도 없는가.
`analysis/correctable_failures.py` + `GOLD_FAILURE_SOURCE.json`.

## 읽는 법

**"환각"이라고 부를 수 있는 건 E 16건뿐이다.** 991문항 기준 1.6%.

- **A 4건은 모델이 옳다.** HiTab gold 가 셀 원문의 단위·주석을 그대로 실어서
  (`326 days`, `6 q`, `6:14.60 or`, `(192.1 overs)`) 공식 채점기가 기각한 것이다.
- **C 18건이 가장 큰 몫이고, 값의 출처는 문맥이다.** 셀 값을 보고 산술 변환을 했다.
  환각이 아니라 **단위·규약 오해**다. 특히 `100−x` 8건은 여집합을 답하는 계통적
  오류다(질문이 "X 한 비율"인데 셀이 "X 하지 않은 비율"이거나 그 반대로 읽는다).
- **B 2건은 오독**이다 — 문맥 안에 있는 다른 숫자를 답으로 골랐다.

즉 노이즈를 전부 없애도 남는 실패의 **절반 가까이(C+B, 20건)가 "문맥은 제대로 봤는데
값을 옮기다 깨진 것"** 이다. 이 몫은 `results/cell_id_v2/VERDICT.md` 의 실험 1
(셀 ID 선택 + 코드 값 반환)이 노렸던 채널과 같고, 그 실험은 검색 문맥 조건에서
값 반환 오류를 58 → 11 로 줄이는 데 성공했다. 다만 셀 선택 오류를 그보다 더 늘려
전체로는 기각됐다.

## 주의

- 이 분류는 **사후 진단**이다. gold 좌표·정답을 쓰므로 어떤 예측에도 쓰지 않았다.
- "변환"은 결정적 규칙(`×100`, `100−x` 등)이 예측값을 정확히 재현할 때만 붙였다.
  우연히 맞는 규칙이 있을 수 있으므로 **기전의 증거가 아니라 분류**로 읽는다.
- C 를 정답 처리하면 안 된다. 값이 실제로 다르고, 이 리포는 ±1% 허용오차 채점에서
  추가 통과 92건 중 76건이 오답이었던 전례가 있다(`TABLES.md` 2026-09-09).
