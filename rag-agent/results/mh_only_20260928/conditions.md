## 불일치 목록과 원인 후보 (코드는 고치지 않음)

1. 행·열 단위 답변이 최종 규칙 검색으로 생성돼 있지 않다(v1·v3.3 만). 원인: 2026-09-27 재실행 때 답변 비교군을 고정 청크로 한정했음. 처리 후보: 최종 규칙 검색으로 882 답변 1회 추가(약 50분) 또는 비교군에서 제외.
2. TableRAG(Yu)·표 전체 입력의 답변 기록이 v1 검색 기록을 가리킨다. 색인·입력 텍스트가 두 규칙에서 같음이 해시로 확인돼 있어 수치는 유효하나, 파일 출처가 최종 규칙 기록이 아니다. 처리 후보: 그대로 두고 표 아래 주석 유지.
3. 표 단위 답변 없음. 처리 후보: 답변 비교군에서 제외(검색 표에만) 또는 882 답변 1회.
4. TableRAG(Chen): 원 방법의 LM 질의 확장·프로그램 실행 미재현, 숫자열은 셀 DB 에서 빠짐 → "셀 검색 구성요소만 비교"로 명시 필요(현재 원고 4.2절·부록 H 에 있음). 비교군 유지/제외는 GATE 3 뒤 사용자 결정.
5. 청크 arm 의 Recall@20(단위) 이 1.0 인 이유: 문서당 청크 수 중앙값 5, 최대 12(≤20 문서 100%) — 상위 20 단위 = 문서의 청크 전부. 따라서 단위 k=20 은 청크 arm 에 의미가 없고, 예산 20셀 또는 토큰 예산 표로 비교해야 한다.
6. 무작위 행: 삭제(지시). MT2Net: 제외(지시).
