## 주의

- k 는 검색 단위(본 방법·머리글 제거는 셀 1개, 비교군은 청크·노드·셀 검색 문서) 개수다. 청크 하나에 셀이 여러 개 들어 있으므로 R@k 를 셀 단위 k 와 바로 비교할 수 없다 — '단위당 평균 셀 수' 열과 함께 읽는다.
- 단위당 평균 셀 수·순위 목록 평균 길이는 그 표의 문항 집합에 속한 레코드의 순위 단위 전부로 계산했다.
- RAPTOR·TableRAG(Chen) 은 검색 단계에 LLM 호출이 들어가 200문항만 실행했다.
- TableRAG(Yu) 검색 순위 = 질문 자체로 한 1회차 검색(재정렬 상위 3 다음 나머지 회수 청크). LLM 질의 분해는 들어가지 않는다.
- RAPTOR 요약 노드의 셀 = 자식 노드가 담은 셀의 합집합. RAPTOR 두 행(2,000토큰·575토큰)은 같은 검색 결과에서 문맥 길이 상한만 다르다.
- 검색 표에서 제외한 레코드(gold 셀·순위 단위 없음), 파일 전체 기준: 본 방법(셀 문장) 23건 / 머리글 경로 제거(ablation) 23건 / LangChain 청크 0건 / RAPTOR 0건 / TableRAG(Chen), 원 설정 128토큰 0건 / TableRAG(Yu) 0건.
- 정확도 = 공식 MultiHiertt EM. DocMath = 산술 문항(본 방법 답변 파일의 kind 기준)만 DocMath 허용 비교, 나머지 문항은 공식 EM 과 같다.
- McNemar = 정확 이항 검정(양측). Holm 가족 = 완료된 외부 비교군 LangChain 청크 / RAPTOR 2,000토큰 / RAPTOR 575토큰 / TableRAG(Chen), 원 설정 128토큰 (200문항), LangChain 청크 1개 (882문항, 보정 전과 같음). 머리글 경로 제거·표 전체 입력은 가족에서 빼고 보정 전 p 만 적었다.
- '실행 대기' = 결과 파일 없음, '실행 중 (n/200)' = 200문항 중 n 문항만 기록됨 — 정확도를 계산하지 않았다.
