## Task B -- McNemar 검정력 분석

Connor (1987) 정규근사 표본수 공식. 불일치 비율 pi_d=(b+c)/n 과 차이 pi_diff=(b-c)/n 을 현재 관측값으로 고정하고

    n = [ z_(a/2)*sqrt(pi_d) + z_b*sqrt(pi_d - pi_diff^2) ]^2 / pi_diff^2

alpha=0.05 (양측), power=0.80. z_(a/2)=1.959964, z_b=0.841621.
