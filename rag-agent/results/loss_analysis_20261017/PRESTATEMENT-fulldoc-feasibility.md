# 예비 측정 사전 기술 (2026-10-17, 실행 전) — 검색만, LLM 없음, 본 실험 아님

목적: "LangChain 을 크게 앞서는 정당한 조건" 후보인 **문서 원문(본문 문단 + 표) 조건**이 성립하는지, 정답 셀 포함률(검색)만으로 먼저 본다.
근거: 표만 남긴 문서는 평균 4.20 청크(중앙값 4, 531/882 는 4개 이하)라 LangChain 상위 4개가 셀의 91.3% 를 덮는다 — 사실상 문서 전체 입력. 문단을 합치면 청크 약 19개, 4개가 22% 를 덮는다.

조건(둘 다 같은 문서·같은 질문 882·같은 인코더 bge-base·같은 토큰 길이):
- LangChain: 문단("\n\n" 연결) + 표 markdown 을 한 문서로, 튜토리얼 분할기(1,000자/겹침 200), 코사인 상위 4개.
- 본 방법: 셀 문장(v3.3u·s3c) + 문단 문장 단위(문장 분리, 머리글 없음)를 한 색인으로, α=0.7 minmax(dense)+0.3 minmax(BM25), 점수 순으로 LangChain 4개 청크의 토큰 길이까지. BM25 IDF 는 882 문서 안 단위로 계산(본 파이프라인은 train 전체 — 차이 기록).
- 참고: 표만 문서에서 LangChain 상위 1·2·4개 대 같은 토큰의 본 방법(입력 길이 사다리).

예측(실행 전):
1. LangChain 문서 원문 상위 4개 정답 셀 전부 포함: 60~75% (표만 문서 98.3% 에서 하락).
2. 본 방법 문서 원문(셀+문장 색인), 같은 토큰: 90% 이상.
3. 표만 문서 사다리: 청크 1개(≈300토큰)에서 LangChain 55~65%, 본 방법 85% 이상.
판정 기준(이 측정의 쓰임): 1 과 2 의 차이가 15%p 이상이면 "문서 원문 조건" 을 본 실험(사전등록, 답변 생성, 마지막 줄 채점)으로 올린다. 아니면 이 노선은 접는다.
