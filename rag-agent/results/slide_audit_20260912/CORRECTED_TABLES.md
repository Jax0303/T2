# 발표 표 교체안

공통 조건: HiTab test의 단일 셀 조회 991문항, BGE-base-en-v1.5 + BM25 (alpha=.7), Qwen2.5-7B-Instruct 4bit, neutral 프롬프트. 전체 시스템 재현이 아닌 표현 적응 비교. 수치는 검증된 evaluation_v2만 사용한다.

| 표현 | 검색 정확도 |
|---|---:|
| 본 방법: 셀 값 + 전체 계층 헤더 경로 + 표 제목 | .9142 |
| RowCol: 행·열 교집합 Markdown, leaf 헤더 (HiTab 적응) | .5126 |
| Huawei에서 착안한 문자 청킹 (native splitter, 1,000자/200자 중첩) | .6771 |

| 표현 | 답변 EM |
|---|---:|
| 본 방법: 셀 값 + 전체 계층 헤더 경로 + 표 제목 | .7074 |
| RowCol: 행·열 교집합 Markdown, leaf 헤더 (HiTab 적응) | .3290 |
| Huawei에서 착안한 문자 청킹 (native splitter, 1,000자/200자 중첩) | .5257 |

주의: RowCol leaf는 상위 계층 레이블을 생략하므로 정보 손실이 있다. 이를 계층 정보가 동등하게 제공되는 비교라고 설명하지 않는다. 현재 별도로 수행하는 전체 경로 복원 진단은 처치의 효과를 분석하는 사후 실험이다.

고정 청킹 및 MT2Net 착안 표현의 과거 점수를 이 새 프롬프트 표에 혼합하지 않는다. 두 표현의 동일 조건 v2 실행은 아직 준비되지 않았다. 5개 방법의 완성된 새 비교표가 필요하면 같은 v2 계약으로 추가 생성해야 한다.

셀 예산은 20셀 도달 시 마지막 검색 단위 전체를 추가한 뒤 멈추는 정책이다. 실제 주지표 평균 전달 셀은 본 방법 20.0, RowCol 22.9, Huawei 청킹 54.4다. 엄격하게 같은 20셀을 제공한 실험이라고 표기하지 않는다. Huawei 청킹 문서 26/1,108은 BGE 512토큰 입력 한계를 초과하여 명시적 절단 정책을 사용했다.

자동 EM은 HiTab 수치 비교를 사용하는 로컬 텍스트 어댑터다. 사람 판정 점수와 별도다. 원본 논문 점수와의 직접 비교에는 데이터·모델·평가 프로토콜 일치 검증이 추가로 필요하다.
