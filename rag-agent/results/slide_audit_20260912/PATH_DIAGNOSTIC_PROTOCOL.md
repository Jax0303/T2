# RowCol 헤더 전달 진단

2026-09-12. 기존 test 결과를 본 뒤 발견한 정보 손실의 사후 진단이다. 독립된 성능 검증 또는 원본 RowCol 전체 재현으로 주장하지 않는다.

처치: 기존 rowcol_v2의 선택된 셀·순서(행/열 정렬)·값·질문을 고정하고 행/열의 leaf 라벨만 전체 경로로 복원한다. 검색을 다시 하지 않으며 gold로 문맥을 고르지 않는다. 모든 1,584 레코드의 근거 좌표와 hit 판정이 그대로인지 검사한다.

생성 대상: 사전 정의된 단일 셀 조회 991건 전부. 비교는 동일 문항의 기존 leaf 답변과 수행한다. Qwen2.5-7B-Instruct 4bit revision a09a35458c702b33eeacc393d103063234e8bc28, neutral prompt, seed 42, greedy, max_new_tokens 64를 유지한다. 문맥 길이 증가는 헤더 복원의 일부이므로 보고한다.

판정: 순정답 변화, 새 정답/새 오답, paired McNemar 검정, 전체 991건 및 공통 hit 403건을 보고한다. 개선이 없으면 그대로 보고하고 추가 프롬프트를 골라 재시도하지 않는다. label collision 유무별 결과는 사후 기전 진단이며 별도 주지표로 취급하지 않는다. 차이 전체를 헤더 손실에 귀속하거나 모든 비교군이 검증됐다고 선언하지 않는다.

사람 판정은 별도 보조 지표다. 자동 EM과 원본 예측은 수정하지 않는다. MultiHiertt 성능 실행은 이번 비교의 미해결 항목을 확인한 뒤 결정한다.
