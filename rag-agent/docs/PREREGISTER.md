# 개정 5 — 2026-08-31, 채점 규칙 확정 + hitab_lookup 확장 (결과 관측 전 결정)

Phase 4c의 **진단**(규칙별로 몇 건이 뒤집히는지)과 검정력 분석을 보고 내린 결정이다.
확장 표본(129건)의 리더 결과는 아직 관측하지 않았다.

1. **채점 규칙에 R1만 추가한다.** 수치 정답에 한해 상대오차
   `|pred-gold| / |gold| < 0.01`을 허용한다.
   근거(사용자 제시): arXiv:2604.01733 Number Match의 상대허용오차 관행.
   **R2/R3/R4는 채택하지 않는다.**
   - R2 기각 사유: HiTab의 `aggregation='div'` 정답은 퍼센트가 아니라 **비율**로
     기록돼 있다(예: `answer=[0.222462]`, `answer_formulas=['=B5/B4']`). 즉 퍼센트
     표기 통일은 형식 문제가 아니라 값 문제를 덮는 규칙이 된다.
   - R4 기각 사유: 절댓값 비교는 `aggregation='opposite'`(`answer_formulas=['=-E15']`)
     문제를 소거해 버린다. 부호를 맞추는 것이 과제의 일부다.
2. **R1은 5개 pool 전체에 일괄 적용**한다. 산술 pool에만 적용하지 않는다.
3. **`hitab_lookup` 표본을 189로 확장**한다. 근거: Phase 4c 검정력 분석에서
   현재 b=17, c=9, π_d=0.4333, π_diff=+0.1333을 고정했을 때 alpha=0.05(양측),
   power=0.80에 필요한 n이 189다. 기존 60건을 전부 포함하고 129건을 추가 추출한다
   (`seed=42`). `gold_cell`도 축소 없이 129건 전량 실행해 60+129=189로 맞춘다.
   **다른 pool은 확장하지 않는다.** 사유: 필요 n이 pool 크기를 넘는다
   (aitqa 2117 > 451, rhb_fact 8946 > 164, hitab_arith·rhb_num은 b=c라 정의되지 않음).
4. **이후 표본 변경 없음.**
