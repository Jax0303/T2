## 왜 2단계가 필요한가

1단계는 **기성품** `BAAI/bge-base-en-v1.5`로만 했다. 현재 최고 arm
`models/bge-base-cell-ft-a0`는 **페이지 제목 없는 셀 문장으로 파인튜닝**됐으므로
인덱스만 바꾸면 학습/추론 불일치가 섞인다. 같은 문장으로 다시 학습해야 한다.

## 개입

`models/bge-base-cell-ft-a0`와 **한 글자도 다르지 않은 레시피**에서 `--title-mode page`
하나만 바꾼다.

```
base=BAAI/bge-base-en-v1.5, population=hitab_train_fit_lookup_all,
epochs=2, batch=32, lr=2e-5, seed=42, neg-per-query=4, neg-cross=0,
multi-gold=skip, query-prefix=none, cell-scheme=S3c
```

산출 `models/bge-base-cell-ft-p0`. 학습과 인덱스가 **같은 `effective_titles`를 통과**한다
(train 코퍼스 2,043표 중 **1,023표(50.1%)** 의 제목이 바뀐다).

## 선택 규칙 — dev를 보지 않는다

α는 **`hitab_train_sel_lookup_all`(756)에서만** 고른다. 격자
α ∈ {0.0, 0.3, 0.5, 0.6, 0.7, 0.8, 0.9, 1.0}, setEM@10 argmax.
동률이면 작은 α. **그 다음 dev/test는 확정 1회씩만 잰다.**

대조 arm a0도 **같은 sel 격자**로 다시 재서 matched α에서 비교한다
(a0의 sel 최적은 α=1.0, 2차 핸드오프 §2).

## 예측 (숫자, 실행 전 고정)

기준: a0 = sel .8386 / dev .9145 / test **.8869** (전부 setEM@10).

| 항목 | a0 (실측) | p0 예측 |
|---|---:|---|
| sel setEM@10 | .8386 | **.845 (.825–.865)** |
| dev setEM@10 | .9145 | **.920 (.910–.930)** |
| **test setEM@10** | **.8869** | **.893 (.882–.904)** |
| dev R@1 | .6819 | **.700 (.680–.720)** |
| dev multi setEM@10 | .7576* | .74 (.68–.80) |
| train_loss | .4548 | .46 (.40–.52) |

\* dev multi는 b0 값. a0은 .6667.

**방향 예측**: p0 > a0. 이득은 1단계(기성품 전체 R@1 +.0096)보다 **크지 않다** — 그때는
표 오인이 .4767에서 .0233으로 갈 여지가 있었고, a0은 이미 표를 더 잘 고른다
(a0 dev 표 오인 .1301 vs 기성품 .1590 추정).

**목표(.90)에 닿는가**: 예측 구간 상단이 .904다. **닿을 수도, 못 닿을 수도 있다고
미리 적는다.** 점추정 .893은 목표 미달이다.

## 반드시 성립해야 하는 것 (아니면 버그)

- 학습 로그가 `[title] mode=page 제목이 바뀐 표 1023/2043`을 찍는다.
- α=0.0(BM25 단독) 칸이 a0과 **동일** — 인코더 무관 칸, 산술 통제.
  단 **셀 문장이 바뀌었으므로 BM25도 바뀐다.** 이 칸은 a0과 달라도 되며, 대신
  p0의 α=0.0과 "기성품 page 모드의 α=0.0"이 같아야 한다.
- 어떤 α에서도 R@1 ≤ setEM@10.
- test는 **한 번만** 잰다.

## 주검정

**sel 756건, p0 vs a0, matched α, setEM@10 페어드 exact McNemar.**
유의하지 않으면 **arm을 바꾸지 않는다** — a0이 그대로 최고 arm으로 남는다.

## 기각 조건

sel 주검정이 유의하지 않으면 기각한다. 그러면 1단계의 이득이 파인튜닝에 흡수되어
사라진다는 뜻이고, 페이지 제목은 기성품에서만 도움이 된다.

## 이 실험이 판정하지 않는 것

- 답변 EM (CLAUDE.md §3, 1단계 판정은 검색 지표).
- **test의 totto 표 비율.** dev는 10.4%다. test가 낮으면 이득도 작다. 이 값은
  확정 측정 때 같이 기록하되 **선택에는 쓰지 않는다.**
- 표 내부 셀 선택. 이 개입은 그쪽에 닿지 않는다 (1단계에서 72%가 그쪽으로 옮겨갔다).
