# 사전등록 — MultiHiertt 표 고유 라벨 (2026-09-13)

## 방법 정의 (사용자 확정, `CLAUDE.md` §1)

셀을 다른 셀과 구별되게 만드는 데이터로 문장을 생성하고 그 문장을 임베딩한다.
문장 = **고유 라벨** + 행 경로 + 열 경로 + 셀 값. MultiHiertt 첫 실행(v1, v2)은 라벨 없이
돌았으므로 **라벨 제거 조건**이다. 이 사전등록은 방법 정의에 있는 입력을 복원한다.

## 라벨 후보 (데이터셋 문단에서만, 생성하지 않는다)

MultiHiertt 문단 목록은 표 자리를 `## Table N` 으로 표시한다(train 600문서 전부, 표시 수 = 표 수).

- **L0** 라벨 없음 (현행)
- **L1** 표시 직전의 비어 있지 않은 문단 문장 그대로
- **L2** L1 이 `:` 로 끝나거나 25단어 이하일 때만 쓰고, 아니면 라벨 없음

표 번호·문서 id 같은 인위적 식별자는 후보가 아니다(질의와의 유사도에 기여하지 않음).

## 선택 기준 — **validation 분할에서만**, 검색 정확도를 보지 않고

정의가 "유사도를 구별되게 하는 데이터"이므로, 규칙은 셀 문장의 **구별력**으로 고른다.

- **U_doc (주)**: 같은 문서 안에서, 값을 뺀 문장(라벨+경로)이 값이 다른 다른 셀과 같은 셀의 비율.
- **U_corpus (보조)**: 같은 비율을 분할 전체에서.
- **가드**: 문장이 인코더 한계 512토큰을 넘는 비율 1% 미만.

U_doc 이 가장 낮은 규칙을 채택한다. 차이가 0.5pt 미만이면 문장이 짧은 쪽을 채택한다.
헤더 규칙은 v2 로 고정한다.

## 공정성

- 제목 칸이 있는 모든 arm 에 **같은 라벨**을 넣는다: chunk `# 제목`, Huawei `Table name`,
  RowCol `# 제목`. HiTab 에서 쓴 규칙과 같다.
- MT2Net 원문 문장은 논문 정의상 라벨이 없으므로 그대로 둔다. 대조군으로 `MT2Net 문장 + 같은 라벨`
  을 추가한다.
- gold 문맥 조건도 색인과 같은 라벨을 붙여 렌더링한다(HiTab 에서 제목을 빠뜨린 결함 전례).
- 최종 측정은 train 분할 2,878건(v2 모집단), 라벨 있음/없음 둘 다 싣는다.

## 예측

1. 본 방법 검색 정확도는 **corpus 범위에서** 오른다(HiTab 에서 라벨 효과가 건초더미와 함께 커졌다).
2. doc 범위(문서당 표 3.89개)에서는 변화가 작다.
3. 라벨이 잡음 문장(각주·본문)을 섞으면 떨어질 수 있다. 이 리포는 생성한 제목으로 EM 이
   .3082 → .2239 로 떨어진 기록이 있다(`CLAUDE.md` §5). 떨어지면 그대로 싣는다.
4. MT2Net 문장 + 라벨 대조군은 본 방법과 구별되지 않는다 — 라벨 + 경로가 같은 정보이기 때문.
   이 경우 논문의 주장은 "문장 형태"가 아니라 "구별 데이터 선택"이 된다.
