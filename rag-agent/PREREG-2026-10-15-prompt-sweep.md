### 단계
1. **모델 선택**: 두 모델 × 변형 2개(원문 `R0X0F0B0D0C0E0`, 전부 켬 `R0X1F1B1D1C2E1`) × A·C, dev 395. **S 평균이 높은 모델**(차이 0.5%p 이내면 Qwen3.5-4B). bf16 적재·생성이 메모리를 넘기면 그 모델 탈락(기록).
2. **전수 탐색**: 선택 모델로 **R 을 뺀 6축 완전 요인 144 변형** × A·C × 395(= 113,760 생성). 그 뒤 S 상위 3 변형에 R1 을 얹은 3개 추가(총 147). R 은 효과가 가장 작을 것으로 봐 요인에서 뺐다(사전 판단).
3. **선택**: **P\*** = S 최대(동률이면 출력 토큰 평균이 적은 쪽). 함께 적는 것: P_C = C 의 W 최대, P_A = A 의 W 최대, 축별 주변 평균 S.
4. 참고 행(판정에 안 씀): 선택 모델이 Qwen3.5-4B 면 P\* 생각 모드(최대 2,048 토큰) dev 한 번 — 09-29 결정(생각 모드 안 씀)은 유지하고 수치만 적는다.

## 882 확인 (선택 모델, 같은 레코드)
- 실행: ① 원문 지시문 A·C(새 LLM 의 기준선) ② **P\* A·C(주 결과)** ③ P_C ≠ P\* 면 C 에 P_C, P_A ≠ P\* 면 A 에 P_A("각자 최선" 보조).
- 비교(같은 문항 정확 McNemar, Holm 묶음): **주 = P\* 본 방법 대 P\* LangChain**. 보조 = 원문 본 방법 대 원문 LangChain / P\* 대 원문(입력마다, 지시문 효과) / P_C 본 방법 대 P_A LangChain.
- 유형별 표(조회 셀1·2+, 산술 셀1·2+, 예/아니오, 개수 세기). 같은 입력의 Qwen3-8B 4비트(54.0/49.4)·GPT-4o(63.5/62.6) 결과를 참고 행으로.
- 채점 코드는 건드리지 않는다. 예/아니오 낱말 없는 출력은 Claude 가 10-13 기준으로 판정해 표로 남기고 사용자가 확인한다.

## 예측 (실행 전 고정)
- 1단계: Qwen3.5-4B 가 2507 보다 S 0~5%p 높다. 원문 지시문에서 두 모델 모두 Qwen3-8B 4비트(dev C 35%, A 약 31%)보다 5~15%p 높다.
- 축별 주변 효과(S): C1·C2 +2~5%p(공식 EM 은 0→30%대로), F1 +1~3, B1·B2 산술에서 +3~8(조회는 ±1), D1 +1~3, E1 +2~5, X1 0~+2(C 입력에서 더 큼), R1 ±1.
- P\* 의 S: 원문 대비 **+8~15%p**. 잘림(768 초과)은 B1·B2 에서 1% 미만.
- 882: P\* 에서 본 방법 58~66%, LangChain 55~63%. **본 방법 대 LangChain 차이는 원문(+4.6%p, 유의)보다 줄어 0~3%p**, 유의하지 않을 확률 50%. 지시문 효과(P\* 대 원문)는 두 입력 모두 유의(p<.001).
- 위험: 144 변형 중 최대를 고르면 dev 수치는 낙관(승자의 저주, 약 2~4%p) — 882 가 판정. 두 입력 모두 지시문으로 오르면 "셀 문장 형식 이득"(cellform 10-12)은 사라질 수 있다 — 그 결과도 그대로 싣는다.
- 시간(사전 추정): 4B bf16 묶음 생성 0.3~0.5초/건 → 전수 약 10~16시간. 실측은 이탈 기록에.
