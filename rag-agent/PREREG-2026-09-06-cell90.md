## E1 — 인코더를 모든 질의 종류로 재학습 (`p1`)

p0 는 단일 셀 조회(fit 2,911)로만 학습했다. p1 = 같은 레시피(bge-base, 형제 negative 4, 2 epoch,
lr 2e-5, page 제목)에 학습 풀만 `hitab_train_fit_alltypes`(3,899 질의: 단일+다중+산술, 표 기준
fit/sel 분할 유지)로 바꾸고 `--multi-gold all`(질문, gold 셀 하나)마다 1행. **α 는 0.8 고정, 선택
없음** (α 는 0.5–1.0 에서 구별되지 않는다고 이미 측정됨). dev/test 각 1회.

예측 (all-covered@10):
| | 기준 p0 | 예측 p1 | 구간 |
|---|---:|---:|---|
| 산술 dev | .5509 | .66 | .60–.72 |
| 산술 test | .7374 | .80 | .75–.85 |
| 다중 dev (n=31) | .8065 | .84 | .74–.92 |
| 단일 dev @10 | .9468 | .945 | .935–.955 |
| 단일 dev @1 | .7281 | .72 | .70–.74 |

기각: 단일 dev @10 이 .01 넘게 떨어지거나 산술 dev @10 이 +.05 미만이면 p1 을 채택하지 않는다.
채택 시 test 는 1회만 본다.

## E4 — 리더 답변 모드: 값만 → 풀이 후 값 (`--answer-mode cot`)

산술의 리더 천장이 dev .3714 / test .5464 (`results/stage3/VERDICT.md`). 프롬프트가 "값만, 32토큰"
이라 7B 가 계산을 못 편다. cot 모드: "CONTEXT 만 써서 단계별로 계산하고 마지막 줄에 `Answer: <값>`",
max_new_tokens 256, 마지막 `Answer:` 뒤를 채점. 리더·채점기·조건 그대로.

예측 (산술, `gold` 조건 = 리더 천장): dev .3714 → .55 (.45–.65), test .5464 → .68 (.58–.78).
단일 셀 `gold` 는 움직이지 않아야 한다 (dev .9024 ± .02). `top10` 산술 dev .1429 → .28 (.20–.36).

## E3 — 도메인 내 크로스인코더 재정렬기 (`ce-cell-p0`)

기성품 재정렬기는 p0 위에서 해로웠다 (hit@1 .7193 → .6181). E3 는 `bge-reranker-base` 를
train fit 풀에서 학습한다: positive = gold 셀 문장, negative = **p0 dense 가 상위 20 안에 올린
오답 셀 7개** (형제가 대부분). 1 epoch, bs 16, max_len 224. 추론은 p0 hybrid α=0.8 의 top-10 을
다시 정렬한다 — top-10 밖은 못 만든다 (@10 불변이 산술 통제).

예측 (단일 셀 dev clean 809, all-covered@k = hit@k):
| | 재정렬 전 | 예측 후 | 구간 |
|---|---:|---:|---|
| @1 | .7281 | .79 | .76–.82 |
| @3 | .8714 | .91 | .89–.93 |
| @10 | .9468 | .9468 | 정확 일치 (통제) |

답변 EM (단일 dev, `retrieved_answer_em --rerank-ks 10`): `rr10` .70 (.66–.74) vs `top1` .6807;
`rr10_3` .74 (.70–.78) vs `top3` .7157. 기각: `rr10` 이 `top1` 을 짝지은 검정에서 못 이기면
(p ≥ .05) 채택하지 않는다. 채택 시 test 1회.

### E1 판정 (dev 를 본 뒤, test 실행 전 기록 — 2026-09-06)
산술 dev @10 .5509 → **.6407** (+.090, 구간 .60–.72 안). 단일 dev @10 .9468 → .9481 (기각 조건 아님).
→ **규칙대로 p1 채택, test 1회.** 단, 사전등록이 다루지 않은 비용이 하나 있다: 단일 dev **@1 .7281 → .6959**
(−.032, 예측 구간 .70–.74 아래). 다중 dev @5 .5806 → .7097, @10 동일 (n=31).
E3(재정렬기)는 채택된 p1 위에서 학습·평가한다 — 예측표의 "재정렬 전" 기준값은 p1 의 .6959 / .8591 / .9481 로
읽고, 예측치(.79 / .91 / @10 불변)는 그대로 둔다.
