## 판정 규칙(결과 전 고정)
- **다수결 D 대 A p<.05 이고 D 가 세 실행 모두에서 A 보다 많이 맞히면** "채운 부분 표가 LangChain 청크보다 답변을 더 맞힌다(3,072 토큰, 882)"를 주 결론으로 쓴다.
- 다수결 p<.05 이지만 한 실행이라도 역전이면 "유의하나 실행 간 불안정"으로 조건부. p ≥ .05 면 "우연과 구별 못 함"으로 보고하고 D 대 A 우위 주장은 하지 않는다(D 대 C 가 유의해도 주 결론 아님).

## 예측(확률; 실행 전 고정)
- 새 실행 각각 D − A ∈ [+5, +35]: 80%. 세 실행 모두 D > A: 70%. **다수결 McNemar p<.05: 45%.** 판정 규칙(주 결론) 충족: 40%.
- D 대 C 다수결 p<.05: 90%. C 대 A 다수결: 차이 ≤ 15 일 확률 70%.
- 실행 간 한 팔 차이 ≤ 20: 80%.
- 빗나가면 그대로 적는다.
