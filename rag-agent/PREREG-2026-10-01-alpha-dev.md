# 사전등록: 하이브리드 가중치 α 검증 집합 비교 — 2026-10-01, 실행 전

## 배경
- 원고 3.3.4 의 `0.7 × minmax(cosine) + 0.3 × minmax(BM25)` 는 연구 초반 고정값이며(CLAUDE.md §2.2 "값 자체는 임의"), 원고에 선택 근거가 없다.
  HiTab dev 에서 0.1~0.9 중 0.7 이 R@1 최고였다는 기록(`results/retrieval_improvement/`)은 있으나 MultiHiertt 에서는 없다.
- 문헌: Bruch·Gai·Ingber (ACM TOIS 2023) 는 같은 min-max 볼록결합에서 α=0.8 채택, 0.6~0.8 에서 일관된 향상, 데이터셋별 적은 질의 수로 튜닝 권고.
  Wang·Zhuang·Zuccon (ICTIR 2021) 은 BM25 0.3 / dense 0.7 에서 모든 데이터셋에서 dense 단독보다 높았다고 서술.

## 조건
- 집합: MultiHiertt 검증 집합 332문항(`mh_dev_s3c_b50` 과 같은 문항, 전달 셀 수 20 을 고른 집합). 평가 200문항·2,885문항은 쓰지 않는다.
- 본 방법 셀 문장(s3c), v3.3u, bge-base, 예산 50·순위 50, `--cache-dir .cache/rerun_20260926_mh`(셀 임베딩 재사용) — `run_retrieval.sh` 의 dev 명령과 α 만 다름.
- α ∈ {0.0, 0.3, 0.5, 0.6, 0.8, 0.9, 1.0}; 0.7 은 기존 `mh_dev_s3c_b50` 을 그대로 쓴다. α=0 은 BM25 만, α=1 은 코사인만.
- 지표(문서 안 검색): 주 = 상위 20개 셀의 재현율(원고 4.2.2 정의, 문항별 |정답∩상위20|/|정답| 평균). 보조 = 상위 1·5개 재현율, 정답 셀 전부 포함 문항 수(@20).
- 판정: 각 α 대 0.7 을 "정답 셀 전부 포함@20" 으로 McNemar 정확검정(보정 없음).

## 결정 규칙 (결과 전 고정)
- 0.7 이 주 지표 최고이거나, 최고 α 와 0.7 의 차이가 유의하지 않으면(p ≥ .05) **0.7 유지**. 원고 3.3.4 에 "검증 집합에서 α 를 비교하여 확인" 한 문장과 수치를 적는다.
- 0.7 보다 유의하게 높은 α 가 있으면 사용자에게 보고하고, 채택 여부와 평가 200문항 재실행은 사용자 결정 뒤 한다(이 문서 범위 밖).
