## 왜
- dev 395(PREREG-2026-10-19-sentence-form.md)에서 같은 셀을 문장형으로 풀어 쓰면 경로형보다 3~4.5%p 낮았다(미팅의 "문장형이 낮을 리 없다"와 반대). HiTab 쪽 목록은 지금 문장형("In the table 'T', among R, the value of C is V.")이므로, 경로형 목록을 만들어 **HiTab 에서도 같은 방향인지** 확인한다.
- HiTab 문장형은 긴 표 제목이 문장마다 반복돼 같은 토큰에 셀이 15.2개뿐이고(정답 셀 포함 636/691), 경로형은 제목을 첫 줄에 한 번만 두어 35.5개가 들어간다(673/691). 따라서 차이에는 "형태"와 "셀 수"가 함께 들어 있다(같은 T 조건의 비교; dev 의 same 조건은 MultiHiertt 에서 이미 봤다).

## 고정 조건
- 691(PREREG-2026-10-19-hitab-confirm.md 와 같은 문항·검색·T), 입력 Cp = `build_pathform.py`(첫 줄 "Table: 제목" + "행 경로 > 열 경로: 값", 순위대로 T 까지, 부동소수 보정 동일; 실행 전 생성·커밋). 지시문 R0X1F1B2D1C1E0, Qwen3.5-4B, 4,096, 3회(동시 32/24/16). 채점 `score_hitab.py`(Cp 팔 추가) 다수결.
