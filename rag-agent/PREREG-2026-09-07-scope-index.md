# 사전등록 — 헤더 범위 색인: 셀 문장 + 범위 문장 (2026-09-07)

**실행 전 작성.** 사용자 지시: 셀 문장 임베딩 프레임은 유지하되 MT2Net 과 갈라지는 설계로 더 좋게, 산술에서 표
통째 투입보다 좋게, 비교는 발표된 논문 수치가 주가 되게. 결과를 보고 규칙을 바꾸지 않는다.

## 설계

색인 단위 = **셀 문장 + 헤더 범위 문장**. 범위 = 헤더 트리의 노드가 덮는 셀 집합:
- `row`  행 경로 R 전체(모든 열):  "In the table 'T', among R, the values are: C1 = v1; C2 = v2; …"
- `col`  열 경로 C 전체(모든 행):  "In the table 'T', for C, the values are: R1 = v1; R2 = v2; …"
- `rgrp` 행 조상 경로 P × 열 C:     "In the table 'T', among P, the values of C are: leaf1 = v1; …"  (P 의 자식 행들)
- `cgrp` 열 조상 경로 Q × 행 R:     대칭
같은 인코더·같은 hybrid 색인에 셀과 범위를 함께 넣는다. 셀 단위(1셀)와 범위(8~12셀)와 표(139셀)를 **넘긴 셀 수**로
맞춰 비교한다: 상위 청크부터 셀 합집합을 쌓아 예산 B 셀에 닿기 전 gold 가 전부 덮이면 1 = `all-covered@B셀`.

라벨은 수식에서: 피연산자 집합 S 의 **최소 덮개 단위**(S ⊇ 를 만족하는 단위 중 셀 수 최소; m=1 이면 셀 자신).
덮는 범위가 없으면 셀마다 1행. 학습 = p1 레시피(bge-base, 형제 negative 4, 2 epoch, lr 2e-5, page 제목),
positive 만 셀 → 최소 덮개 단위로 바꾼다 (`p2`). negative 는 같은 표의 같은 종류 단위.

## MT2Net 과의 차이 (논문에 쓸 문장)
단위(셀만 → 셀+헤더 범위) · 검색(문서 내 크로스인코더 → 코퍼스 전체 bi-encoder ANN) · 라벨(근거 주석 → 표 구조와
수식에서 유도, 질의당 비용 불변).

### 3단계 실행 규약 (실행 전 추가, 2026-09-07)
