# 사전등록: 882 확인 실행을 4,096 토큰 표준으로 3회(D·C·A) (2026-10-19, 실행 전)

## 왜
- PREREG-2026-10-19-prompt-table-rule.md 결과로 출력 상한 4,096 을 이후 표준으로 채택했다. 주 결과(882, D 대 A)는 3,072 에서 3회 실행했으므로 같은 표준으로 다시 3회 돌려 보고 숫자를 통일한다. 입력·지시문·규칙 모두 고정이라 선택이 아니다.

## 고정 조건
- 882, 팔 D·C·A(입력 `D882_records`·`C_ours_budget_records`·`A_chunk_md_records`, 기존과 같음), P*(R1X1F1B2D1C1E0), Qwen3.5-4B bf16, vLLM greedy 비생각, 최대 4,096(`--max-model-len 8192`), 3회(동시 32/24/16). 채점 `score_formats2.py` + `score_rep.py`(다수결 McNemar). 스크립트 `run_882_cap4096.sh`.

## 판정(결과 전 고정)
- 4,096 3회 다수결에서 D 대 A p < .05 이고 세 실행 모두 D > A 이면: 논문 주 표 = 4,096 결과, 3,072 결과 = 반복 확인으로 함께 수록.
- 아니면: 둘 다 수록하고 주장은 "D ≥ A(한 조건에서 우연 아님, 다른 조건에서 우연 범위)"로 낮춘다. 어느 쪽이든 두 결과를 모두 보고한다.

## 예측(확률; 실행 전 고정)
- 세 실행 모두 D > A: 80%; 다수결 p < .05: 65%; D − A 평균 [+10, +40]: 75%.
- 팔별 평균이 3,072 대비 ±9 안: 70%. 잘림은 줄지 않음(남은 잘림은 반복 출력): 60%.
- 빗나가면 그대로 적는다.
