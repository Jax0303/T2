# 데이터 사용 이력 — MultiHiertt 노선 (2026-09-14 대조)

MD 서술이 아니라 로더 코드·실행 인자·결과 메타데이터·문항 id 로 대조했다. 새 dev 분할을 만들거나 분할 이름을
바꾸지 않았다. 대조 방법은 §6.

## 0. 요약

- **2026-09-08 합의(`CLAUDE.md` §0.3·§0.4)는 HiTab 노선의 것이다**: 학습 없음, HiTab `test` 1,584 질의만. 이번 대조는
  MultiHiertt 노선만 다시 확인했다(HiTab 결과 메타데이터는 대조하지 않았다).
- **MultiHiertt 노선은 `test` 를 쓰지 않았다.** 로더 `scripts/mh_arms.py` `load_population(split)` 은
  `load_dataset("bevaya/MultiHiertt", split=split)` 이다. 로컬 캐시(snapshot `ae21d2d80c97fdfbcde43aa4c51bdd90b169522d`)에는
  `train` 7,830 행·`validation` 1,044 행 두 분할만 있고 `test` 를 요청하면 `Unknown split "test"` 다. 두 분할 uid 겹침 0.
- **평가(검색 정확도·답변 EM)는 train, 리더 파일럿과 라벨 규칙 선택은 validation** 에서 했다. 기존 사전등록
  (`PREREG-2026-09-13-multihiertt-arms.md`)은 train 사용을 "학습이 아니라 평가"로, test 는 gold 비공개로 적었다. 후자는
  이번에 확인하지 않았다 — 확인된 것은 로컬 미러에 test 분할이 없다는 것까지다.
- **모델 학습: 현행 노선 결과에는 없다.** 검색 결과 `arguments.embed_model` 은 전부 `BAAI/bge-base-en-v1.5`, 답변 리더는
  `Qwen/Qwen2.5-7B-Instruct`·`Qwen/Qwen3-8B`(revision `b968826d9c46…`) 4bit 기성품이다. 리포에 학습 코드가 없다
  (`backward`·optimizer·Trainer 검색 0). 2026-09-07 이전 폐기 노선의 MultiHiertt 학습 산출물은 디스크에 남아 있다(§4).
- **평가 결과를 보고 한 설정 선택·규칙 수정은 있다(§3).** 학습은 아니지만, 그 결정에 쓰인 문항은 그 결정의 효과를
  독립적으로 평가하지 못한다.

## 5. interim200 의 지위 (2026-09-14 사용자 지시)

- 분할 이름은 **train** 그대로, id 목록 `results/mh_interim200/ids_200.json` 은 바꾸지 않는다.
- interim200 은 **사후 분석·개발에 사용된 표본**이다. 헤더 규칙 v3 의 결함 사례를 이 표본의 답변 불일치에서 찾았고,
  v3.1·v3.2 는 그 규칙을 좁힌 것이다. 이 200 문항에서 v2 대비 새 규칙의 차이는 규칙이 이 표본에 맞춰진 몫을 포함하므로
  **독립적인 미관측 test 평가가 아니다.** 별도 dev split 이라고 부르지 않는다.
- 1,047 중 나머지 847 문항은 규칙 수정 때 답변 결과를 읽지 않았다. 그러나 v2 설계가 v1 1,047 레그의 오류를 참고했고
  (개별 id 기록 없음) 헤더 규칙 측정은 train 전체 표를 썼으므로, 847 도 새 규칙에 대해 미관측이라고 쓰지 않는다.

## 6. 대조 방법

- 분할·행 수: `HF_HUB_OFFLINE=1` 에서 `load_dataset("bevaya/MultiHiertt", split=s)` 를 train·validation·test 로 호출.
- id: 결과 jsonl 의 `query_id` 를 두 분할 uid 집합과 비교하고, 1,047·200·60 집합 사이 포함·겹침을 셌다.
- 인자: 결과 요약의 `split`·`arguments`·`stratum_cap`·`sample_seed`·`same_queries_as`·`reader_details.revision_resolved`,
  실행 스크립트(`run_*.sh`)와 로그의 `[sample]`·`[pilot]` 줄.
