## 3. 표 내부 셀 오인 156건 — 원인 규명, 처방 실패

`results/sibling/VERDICT.md`, `VERDICT_2.md`.

정답 셀을 밀어낸 1등 셀과 정답 셀의 관계 (기저율은 그 질의의 정답 표 안 비율):

| 관계 | 1등에서 | 표 기저율 | 농축 |
|---|---:|---:|---:|
| **same_row** (행 경로 동일, 열만 다름) | .5000 | .0773 | **6.46x** |
| same_col | .3526 | .1576 | 2.24x |
| sibling_elsewhere (한 마디 차) | .0641 | .4516 | **0.14x** |
| **행/열 정확일치 합** | **.8526** | .2350 | **3.63x** |

- **검색기가 행 헤더(주어)를 붙잡고 열 헤더(연도·지표)를 구분하지 못한다.**
- 넓은 의미의 "형제"는 기저율이 70%라 아무것도 설명 못 한다. 처음 센 91.7%는 무의미했다.
- 계층 특이성(싼 판): 깊이 (1,1) 칸은 표 내부 오인 .0513, 계층 칸 .1947.
  **Fisher p=.0207**, 표 크기 통제 후 p=.0302. 단 **n=39에 사건 2건이라 취약**하고
  **교차 데이터셋 대조가 아니다.**

**개입 기각**: 질문 vs 열 경로 BM25를 점수에 더하는 것 — 전역/표단위/상위10 재정렬
세 형태 전부 단조 하락 (dev 830: .6819 → .6687 → .6241). 질문이 열 헤더를 그대로
말하지 않아서 어휘 일치로는 복구 불가.

## 4. 표 오인 108건 — 제목 충돌 → ToTTo 페이지 제목 복원 (통과)

`results/tableconf/VERDICT.md`, `TOTTO_RECOVERY.md`, `results/titlemode/VERDICT*.md`.

- dev 표 424개 중 **179개(42.2%)가 제목 중복**. `career statistics` 61개.
  **179개 중 176개가 ToTTo(위키).**
- 제목 겹침 질의 표 오인 **.4533** vs 고유 **.0980**, **p=2.1e-13**. 기성품에서도 재현.
- **기각**: `drop`(제목 제거) .4933→.5067, `sig`(희귀 헤더 토큰으로 대체) →.5200.
  둘 다 유의하지 않음. **이유: 필요한 토큰이 코퍼스에 없다.**
- **HiTab의 `title`은 ToTTo의 section_title이고 page_title(개체명)은 버려졌다.**
  질문 토큰 중 표에 없는 비율 .700(겹침) vs .462(고유).
- **매핑 `<배치>_totto<N>-<k>` → ToTTo train N번째 줄(0-based).** 1,851개 전수 셀 대조,
  1,850개가 겹침 0.5 이상. 복원본 **`results/tableconf/totto_page_titles.json`**.
- **통과**: `page` 모드(기성품 bge-base, α=1.0, dev)

| | totto 질의(86) R@1 | totto 표 오인 | 그 외(744) 표 오인 | 전체 R@1 |
|---|---:|---:|---:|---:|

**핵심**: 표 오인이 사라졌는데 R@1은 10.5%p만 올랐다. **86건 중 62건(72%)이 이제 표

## 5. 공백 검증 — 논문 관점

`GAPCHECK-2026-09-02-cell-rerank.md`. **현 상태로는 탑티어 기여 아님.**

- CLTR(ACL 2021 Demo)이 열린 검색 + 셀 단위를 이미 함. TACR(Findings ACL 2023)이 셀
  선택 행·열 정확도 90%+ 보고(평면 표). CRAFT(2025)는 표 단위에서 정지.
- 차별점이 "계층형 표" 하나뿐이면 `기존 방법 + 새 데이터셋` 조합으로 분류된다.
- 살아남는 것: 실패 층위 분해 / 헤더 경로 정확일치의 구조적 농축 / 검색·리더 실패의
  원인 동일성. **전부 분석 기여이지 방법 기여가 아니다.**
- 리뷰어 공격 지점 6개(표본 크기, 단일 데이터셋, 비교 불가 설정, 4-bit 양자화 미반증,
  gold 라벨 오염 미정량, α=1.0 근거가 질의 1건) — 문서 §4.
