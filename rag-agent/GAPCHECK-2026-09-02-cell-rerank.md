# 연구 공백 검증 — 계층형 표의 셀 단위 검색·재정렬

작성 2026-09-02. 리뷰어 관점의 비판적 검증이며, 이 저장소의 측정치를 근거로 함.
대상 주장: **「계층형 표(HiTab)에 대한 열린 검색 설정에서 셀 단위 검색 + 재정렬」이
탑티어 학회 기여가 되는가.**

판정 요약: **현 상태로는 기여 아님.** 근거와 전환 조건을 아래에 기술함.

## 2. 선행연구 대조 — 주장된 공백의 대부분은 이미 점유됨

| 연구 | 열린 검색 | 셀 단위 | 계층형 표 | 비고 |
|---|:---:|:---:|:---:|---|
| CLTR (ACL 2021 Demo, arXiv 2106.04441) | ○ | ○ | ✗ | 76,242표 / 2,005질의, E2E_WTQ·E2E_GNQ |
| TACR (Findings of ACL 2023, arXiv 2305.14682) | ✗ | ○ | ✗ | HybridQA·WTQ. **행·열 선택 정확도 90% 초과 보고** |
| CRAFT (arXiv 2505.14984) | ○ | ✗ | ✗ | 표 단위에서 정지. cross-encoder 없음 |
| 본 연구 | ○ | ○ | ○ | — |

**CLTR이 2021년에 이미 열린 검색과 셀 단위 위치 지정을 함께 수행함.** 남은 차별점이
계층형 표 하나이므로, 리뷰어는 `기존 방법 + 새 데이터셋` 조합으로 분류함.

**TACR이 더 직접적 위협임.** 셀 선택에서 행·열 선택 정확도 90% 초과를 보고함.
본 연구의 표 내부 셀 정확도 78.4%와 대비되나 **동일 지표로 측정되지 않았으므로 현재
비교 불가.** 리뷰어의 질문은 "78.4%가 낮은 값인지 지표 정의 차이인지"임.

정확도 주의: CLTR·TACR이 평면 표를 대상으로 한다는 판단은 각 데이터셋
(WikiTableQuestions, HybridQA, Google NQ)의 알려진 성질에서 도출한 것이며 두 논문
본문에서 직접 확인하지 않음. **MEASURED: NO.**

## 3. 기법 조합을 걷어내고 남는 세 가지

**(가) 실패의 층위 분해 — 표 오인 108건 대 표 내부 셀 오인 156건.**
CRAFT는 표 단위에서 정지하므로 이 층의 데이터가 없음. CLTR·TACR은 평면 표에서 측정함.
계층형 표에서 손실의 과반이 표 내부에서 발생한다는 수치는 확인된 선행연구에 없음.

**(나) 형제 셀이 최고점 distractor라는 구조적 필연성.**
Cuconasu 외(SIGIR 2024, arXiv 2401.14887)는 검색기가 높은 점수를 부여했으나 질문에
직접 답하지 않는 문서가 성능을 가장 크게 해친다는 경험적 관찰을 보고함. 계층형 표에서는
형제 셀이 헤더 경로를 공유하므로 **높은 점수가 구조적으로 보장됨.** 경험적 관찰의
구조적 특수화이며 단순 재현이 아님.

**(다) 검색 실패와 리더 실패의 원인 동일성.**
R@1이 .6819에서 정체하는 원인과 `EM|주입됨`이 .9170에서 .7484로 하락하는 원인이 동일
대상(형제 셀)임. 두 단계를 독립적으로 개선하는 파이프라인 설계에 대한 반론이 될 수 있음.

**세 항목 모두 방법 기여가 아니라 측정·분석 기여임.** 현 상태의 상한은 *ACL Findings
수준의 분석 논문이며 ICML·NeurIPS 수준이 아님.

## 4. 리뷰어가 즉시 공격할 지점 여섯 개

1. **표본 크기.** test 769, 다중 셀 31·33. 다중 셀 결론이 2~3건 이동에 의존함.
   다중 셀 축이 닫혔다는 결론은 현 표본으로 지지되지 않음.
2. **단일 데이터셋.** HiTab만 사용. 계층 구조가 원인이라는 주장은 **평면 표 대조군
   없이 성립하지 않음.**
3. **비교 불가능한 평가 설정.** lookup 전용 부분집합과 자체 동결 모집단을 사용함.
   FORTAP의 HiTab test 실행 정확도 47.0%(ACL 2022, aclanthology 2022.acl-long.82)와도
   CRAFT의 R@1과도 대응되지 않음. 리뷰어의 첫 질문에 현재 답이 없음.
4. **4-bit 양자화.** 리더가 Qwen2.5-7B-Instruct 4-bit NF4임. 양자화는 수치 처리에
   영향을 미침. "리더가 .90에서 막힌다"가 양자화 아티팩트일 가능성이 반증되지 않음.
5. **gold 라벨 오염 미정량.** F 이후 잔여 57건 중 라벨 불일치가 6건 이상 존재하나
   전수 계수하지 않음. 천장 .9313을 제시하면서 오염률을 모르는 상태임.
6. **α=1.0 선택의 근거 취약.** sel에서 α=0.9와의 차이가 질의 1건임. 「Tailoring Table
   Retrieval from a Field-aware Hybrid Matching Perspective」(EMNLP 2025,
   aclanthology 2025.emnlp-main.1409 / arXiv 2503.02251)는 **표 제목은 dense 매칭을,
   헤더와 셀은 sparse 매칭을 선호한다**고 보고함. 셀 단위 검색에서 dense 단독 선택은
   이 보고와 상충하며 근거가 질의 1건임.

## 5. 전환 실험 — 우선순위 순

**실험 1 (최우선, GPU 학습 불필요, 현재 데이터로 가능).**
표 내부 오인 156건에서 **예측 상위 셀과 정답 셀의 헤더 경로 관계**를 측정함.
형제(경로 한 마디 차)에 집중되면 (나)의 구조적 주장이 성립하고 논문의 중심 주장이 됨.
분산되면 가설 기각이며 원인은 계층 구조가 아님. **이 실험 하나가 논문 성립 여부를
결정함.**

→ **실행 완료. 결과 `results/sibling/VERDICT.md`. 가설 지지, 단 주장을 좁혀야 함.**
넓은 의미의 형제(경로 한 마디 차)는 농축 0.14배로 **오히려 회피됨.** 원인은 **한 축의
헤더 경로 정확일치**이며 1등의 85.3%를 차지함(기저율 23.5%, 3.63배). **행 축 6.46배,
열 축 2.24배로 행 축이 3배 가까이 심함** — 검색기가 행 헤더를 붙잡고 열 헤더를 구분하지
못함. `same_address` 6건은 경로가 완전히 같아 경로 기반 재정렬의 원리적 상한임.
**단, 계층 특이성은 증명되지 않음 — 실험 2가 여전히 필수임.**

**실험 2. 평면 표 대조군.** 동일 파이프라인을 WikiTableQuestions 또는 HybridQA에 적용함.
표 내부 셀 정확도가 평면에서 90%대, 계층형에서 78.4%로 갈리면 계층 특이성이 증명됨.
**이 대조군 없이는 (가)(나)(다) 전부 HiTab 특이 현상으로 기각됨.**

**실험 3. 양자화 반증.** gold 조건 830건만 fp16으로 재실행함. 리더 호출 830회. (4) 제거.

**실험 4. 라벨 오염 정량.** F 이후 잔여 57건 전수에서 라벨 오류 비율을 확정함.

**실험 5. 헤더·셀에 대한 sparse 가중 재검토.** EMNLP 2025 보고와 대조함. (6) 대응.

## 6. 종합 판정

- **현 상태**: 탑티어 기여 아님. CLTR과의 차별점이 데이터셋 하나임.
- **실험 1이 형제 집중을 보이고 실험 2가 평면 대조를 확보하면**: 「계층형 표의 헤더 경로
  공유가 검색과 생성 양쪽에서 동일한 실패를 유발한다」는 구조적 주장이 성립하며
  *ACL 본회의 수준의 분석 논문이 됨.
- **헤더 경로를 명시적으로 사용하는 재정렬 방법이 추가되면** 방법 기여가 생기며
  탑티어 진입이 가능함.
- **cross-encoder 재정렬을 그대로 붙이는 것만으로는 기여가 되지 않음.** TACR이 정렬 기반
  셀 선택을 이미 수행함.

강점 한 가지를 명시함. **사전등록을 실행 전에 커밋하고 예측 적중률까지 기록하는 규율은
이 분야에서 드물며, 예측이 빗나간 항목을 그대로 보고한 점이 신뢰 근거로 작동함.**
논문에서 전면에 배치할 것을 권함.
