# 사전등록: 셀 문장의 문장 형태(경로형 대 문장형) × 꺽쇠 경로 설명 지시문 — dev 395, 2회 실행 (2026-10-19, 실행 전)

## 왜
- 미팅(2026-10-19) 지적 둘. (1) "일반적인 문장 형태로 셀 문장을 만들면 답변 정확도가 더 떨어지는가? 말이 안 된다" — 직접 비교한 적이 없다(HiTab 은 문장형 "In the table…", MultiHiertt 는 제목이 없어 경로형 "행 > 열: 값"이라 데이터셋이 달라 비교 불가). (2) 셀 문장이 꺽쇠(' > ')로 경로를 적는데 지시문이 그 표기를 설명하지 않는다 — 설명을 넣어야 하지 않나.
- 그래서 같은 셀을 세 형태로 만들어 같은 LLM·지시문에서 비교하고, ' > ' 표기를 설명하는 지시문 수준(X3)을 모든 팔에 같이 시험한다.

## 고정 조건
- dev 395(validation 332 + train lookup_m2+ 63; 평가 문항 882 는 안 씀), Qwen3.5-4B bf16, vLLM greedy 비생각, 최대 4,096 토큰, 2회(동시 32/20). 채점 `score_formats2.py` 마지막 줄. 판정은 2회 평균.
- 입력 7개(`build.py`, 실행 전 생성·커밋; 기존 dev_C 를 Cp 로 글자 단위 재현 확인):
  - A LangChain 청크 4개(dev_A_records), D 채운 부분 표(format_dev D_records), **Cp 경로형**(지금 쓰는 "행 경로 > 열 경로: 값", T 까지).
  - **S1** 문장형(꺽쇠 유지) "Among <행 경로 ' > '>, the value of <열 경로 ' > '> is <값>." / **S2** 문장형(꺽쇠 없음, ', ' 로 연결).
  - 각각 두 조건: `same` = Cp 와 같은 셀(토큰 한도 무시, 길어짐) / `T` = 순위대로 T 까지(셀 수 줄어듦). → S1same·S2same·S1T·S2T.
- 지시문 2개: P* = R1X1F1B2D1C1E0, **P*N = R1X3F1B2D1C1E0**(X3 = X1 + "Header paths are written from the top-level header down to the sub-header, separated by ' > ' (for example 'Revenues > 2019' means the 2019 column under Revenues)."). `scripts/prompt_variants.py` 에 X3 추가(원문 불변 assert).

## 판정 규칙(결과 전 고정)
- (a) 문장 형태 효과(같은 셀, P*): S1same − Cp, S2same − Cp 의 2회 평균. |차| ≤ 8 → "문장 형태는 답변에 영향 없음"; ≤ −9 → "문장형이 낮다"; ≥ +9 → "문장형이 높다"(그러면 D 의 라벨 표기도 문장형으로 바꿀지 별도 사전등록).
- (b) 같은 토큰(S1T·S2T − Cp): 문장이 길어 셀이 줄어드는 비용. (a) 와 함께 적는다.
- (c) 꺽쇠 설명 X3: S(P) = (A + Cp + D)/3 (2회 평균). **S(P*N) ≥ S(P*) + 6 이고 D(P*N) ≥ D(P*) − 3 이면 P*N 채택**(이후 모든 팔). 팔별 효과(특히 Cp·S1)도 적는다.
- 선택 원칙: 두 입력 평균이 아니라 세 입력(A·Cp·D) 평균. 한쪽에 맞추지 않는다.

## 예측(확률; 실행 전 고정)
- S1same − Cp ∈ [−8, +8]: 60%; ≤ −9: 25%; ≥ +9: 15%. S2same − Cp ∈ [−8, +8]: 55%; ≤ −9: 30%; ≥ +9: 15%(꺽쇠를 빼면 경로 경계가 흐려져 조금 낮을 가능성).
- S1T − Cp ≤ −9: 55%(문장 틀이 셀당 약 6 토큰을 더 써 셀이 약 15~20% 줄어듦); S2T 도 같음.
- X3: 채택 규칙 충족 25%; Cp 에서 +(≥ +4) 45%; D 에서 ±4 안 65%; A 에서 ±4 안 70%.
- 교수 가설("문장형이 낮을 리 없다")이 맞을 확률(같은 셀 조건에서 S1same ≥ Cp − 8): 70%.
- 빗나가면 그대로 적는다.
