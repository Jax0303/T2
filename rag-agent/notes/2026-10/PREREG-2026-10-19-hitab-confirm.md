# 사전등록: HiTab 확인 표본 691(300 밖 모집단 전부)에서 채운 부분 표(D) 대 LangChain 청크(A) — 전체와 행 머리글 깊이별, 3회 실행 (2026-10-19, 실행 전)

## 왜
- 300 결과(PREREG-2026-10-19-hitab-newregime.md): D 258 대 A 249(우연 범위), 이득이 **행 머리글 깊이 3 인 100문항**에 몰림(90 대 80), 깊이 1~2 의 195문항은 165 대 164. 사후 관찰이므로 **새 문항**으로 확인한다.
- 가설: **H1** HiTab 전체에서 D > A. **H2** 격차는 행 머리글 깊이 ≥ 3 에서 크고 ≤ 2 에서는 거의 없다(구조가 깊을수록 격차; MultiHiertt 에서 셀 2개+ 문항에 이득이 몰린 것과 같은 성격).
- 표본 = 사전등록된 991 모집단(mode all·m=1·집계 없음, `scripts/bottleneck_diagnosis.load_primary_population`) 가운데 300 밖의 **691 전부**(선택 없음). 깊이 분포 1: 101, 2: 348, 3: 231, 4: 11(≥ 3 비율 35%, 300 과 같음). 표 304개(300 의 표와 125개 겹치나 문항은 겹치지 않음). 300 은 같은 모집단에서 순위 구간 비례 층화 표본이었으므로 691 은 나머지 모집단이다.

## 고정 조건
- 300 과 같은 조건: 검색(표 안 s3c, α0.7, 상위 100, 같은 기록 파일), 입력 규칙(A = 표 전체 markdown → 1,000자/겹침 200 → bge-base 상위 4; C = 셀 문장 T 까지; D = 채운 부분 표 T 까지), 지시문 R0X1F1B2D1C1E0, Qwen3.5-4B bf16 vLLM greedy 비생각, 최대 4,096(`--max-model-len 8192`), 3회(동시 32/24/16), 채점 `score_hitab.py`(정규화 포함) 다수결 McNemar.
- 입력 생성기 `build_hitab_pool.py` = `build_hitab.py` + 부동소수 표기 잡음 보정 하나(.10g; C 문장·D 칸, 소수 7자리 이상인 수만). 깊이 = 표의 최대 행 머리글 경로 길이(`row_depth_by_query.json`, 실행 전 고정). 스크립트 `run_confirm.sh`, 분석 `analyze.py`([H2] 블록).

## 판정 규칙(결과 전 고정)
- **H1**: 다수결 McNemar D 대 A p < .05 이고 세 실행 모두 D > A → "HiTab 에서도 D > A"를 쓴다. 아니면 우연 범위.
- **H2**: 깊이 ≥ 3 부분(242문항)에서 다수결 McNemar p < .05 **이고** (깊이 ≥ 3 의 D−A %p) − (깊이 ≤ 2 의 D−A %p) ≥ 4%p → "격차는 깊은 구조에 몰려 있다"를 쓴다. 상호작용(두 부분의 불일치 방향 비율 Fisher 정확검정)은 보조로 적는다.
- 300 과 합친 991 수치는 참고로만 적는다(가설을 만든 300 이 섞이므로 주 판정에 안 씀). 보조: D 대 C, C 대 A.

## 예측(확률; 실행 전 고정)
- 전체 D−A(다수결): [0, +30] 70%; D > A 75%; **H1 충족 45%**.
- 깊이 ≥ 3(242): D−A ≥ +10(4%p) 55%; **H2 충족 35%**. 깊이 ≤ 2(449): |D−A| ≤ 10 인 확률 65%.
- C < A 80%; D 대 C p < .05 90%. 잘림: D ≤ 3%, A·C 3~7% 각 65%.
- 빗나가면 그대로 적는다.
