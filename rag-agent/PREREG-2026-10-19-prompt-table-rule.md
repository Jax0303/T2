# 사전등록: 지시문에 "표 또는 표의 일부" 설명과 "표끼리 합산 금지" 규칙 추가 + 출력 상한 4,096 — dev 395, 2회 실행 (2026-10-19, 실행 전)

## 왜
- 채운 부분 표(D)가 LangChain(A)에 지는 48건(882, 3,072) 중 가장 큰 묶음은 다른 표의 같은 이름 행과 혼동·표끼리 합산(약 10건)이다. 표 수 제한(PREREG-2026-10-18-table-cap.md)은 효과가 없었다. 표를 구별할 글(문서 제목·절 제목)은 데이터셋에 없으므로 렌더링으로는 못 고친다 → **지시문 규칙**으로 "여러 표면 머리글이 맞는 표만 쓰고 표끼리 더하지 말라"를 넣는다. 같은 지시문을 두 입력에 똑같이 쓴다(LangChain 도 다른 표 혼동 54건 중 6건).
- P* 의 입력 설명(X1 "표의 셀")은 목록 입력에 맞춘 문장이다. 지금 입력은 표 조각이므로 X2 "표 또는 표의 일부"로 바꾼다(LangChain 청크에도 맞는 설명).
- 출력 상한 3,072 에서 잘림이 팔마다 41~54건(5~6%) 남는다 → 4,096 으로 올려 함께 본다.
- 선택 원칙은 지시문 탐색 때와 같다: **두 입력의 평균(S)으로 고른다**, 한쪽에 맞추지 않는다.

## 고정 조건
- dev 395, Qwen3.5-4B bf16, vLLM greedy 비생각, 최대 4,096 토큰(`--max-model-len 8192`), 실행 2회(동시 32 / 20).
- 팔: A(LangChain 청크)·D(채운 부분 표) × 지시문 {P* = R1X1F1B2D1C1E0, P*T = R1X2F1B2D2C1E0}. `scripts/prompt_variants.py` 에 X2·D2 수준 추가(기존 수준·원문 불변, assert 확인). D2 = D1 의 규칙 6개 + "(7) If the context contains several tables, use the table whose row and column headers match the question; do not add up values from different tables unless the question asks for it."
- 채점 `score_formats2.py`(마지막 줄, 굵은 라벨 허용). 판정은 두 실행 평균.

## 판정 규칙(결과 전 고정)
- S(P) = (A 평균 + D 평균)/2. **S(P*T) ≥ S(P*) + 6 이고 D(P*T) ≥ D(P*) − 3 이면 P*T 를 채택**(이후 모든 팔에 P*T). 아니면 P* 유지.
- 상한 4,096: 같은 지시문 P* 에서 3,072 실행(devcap_run1·2: A 254/257, D 268/267)보다 두 팔 평균이 모두 내려가지 않으면 4,096 을 표준으로(실행이 다르므로 참고 비교, ±6 잡음).
- 채택되면 882 확인은 별도 사전등록(3회 실행, 다수결).

## 예측(확률; 실행 전 고정)
- P*T 가 D 에서 +: 60%; A 에서 +: 50%; **S 기준 +6 이상(채택): 35%.** 규칙 (7) 이 D 의 표끼리 합산을 줄여 D − A 격차가 벌어질 확률 50%.
- 4,096 에서 잘림: 3,072 대비 절반 이하로 줄 확률 60%; 정확도 변화 ±4 안 70%.
- 빗나가면 그대로 적는다.
