# 사전등록 2026-10-20 — 꺽쇠(' > ') 경로 설명 지시문 추가 확인 (새 문항 600, 3입력 × 3회)

## 왜
- 10-19 미팅에서 교수님 요청(③): 셀 문장이 ' > '로 머리글 경로를 적으니 지시문에서 그 뜻을 알려 주어야 한다. 사용자 결정(10-20 17:30): "일단 교수님이 하라고 했음, 추가해 보자."
- 앞선 dev 395 2회(PREREG-2026-10-19-sentence-form.md, 지시문 X3)에서는 효과 없음: LangChain 청크 −4.5, 경로형 목록 −3.0, 잘라낸 표 −1.0(2회 평균, 잡음 ±10 안). 평가 문항에서 다시 확인한다.
- 공정성 조건: 같은 문장을 세 입력 모두에 준다. ' > '는 셀 문장 목록과 잘라낸 표의 머리글에만 있고 LangChain 청크(markdown)에는 없으므로, 문장은 "있을 때의 뜻"을 설명하는 서술이다(Voronov 2024·Sclar 2024 기준: 한 방법에 맞춘 형식의 영향은 지시문 2개 이상에서 결과를 보고해 드러낸다).

## 고정 조건
- 문항: `results/mh_confirm_20261019/ids600.json`(882·dev 밖 새 문항 600, 거의 전부 산술 셀 2개+). 입력 레코드 `D/C/A_records.jsonl` 그대로(같은 검색 순위·같은 토큰 양 T).
- LLM Qwen3.5-4B bf16, vLLM 0.31.0, temperature 0, 비생각, 최대 출력 4,096, 3회(동시 32/24/16) — 기존 P* 실행 run1~3과 같은 설정.
- 지시문: 지금 지시문(R1X1F1B2D1C1E0)에 X3 문장 하나를 더한 R1X3F1B2D1C1E0. 더한 문장(원문 불변, `scripts/prompt_variants.py`):

- 실행 `results/mh_confirm_20261019/run_x3.sh` → `run{1,2,3}x3/`, 채점 `score_x3.txt`(입력별)·`score_x3_pair.txt`(`score_x3.py`: 있음 대 없음 짝 비교, 같은 실행 번호끼리).

## 판정 규칙(결과 전 고정)
비교 1 — 입력마다 "설명 있음" 대 "없음"(같은 600, run i ↔ run i x3):
- **채택(주 지시문에 문장 추가)**: 셀 문장 목록과 잘라낸 표 둘 다 3회 평균 +12 이상(600의 2%p)이고 세 실행 중 2회 이상 p<.05.
- **효과 없음**: 세 입력 모두 3회 평균 변화가 ±12 안 → 교수 요청대로 문장을 넣되 보고·논문에 "효과 없음(수치)"을 명시한다(사용자 결정 10-20; 사용자가 결과 전에 바꾸면 그 결정을 적는다).
- **해침**: 어느 입력이든 3회 평균 −12 이하이고 2회 이상 p<.05 → 넣지 않는다.
- 그 밖(혼합)은 수치를 그대로 적고 결정은 사용자.

비교 2 — 설명 있음 아래 잘라낸 표 대 LangChain 청크(실행별):
- 세 실행 모두 잘라낸 표 > LangChain 이고 각각 p<.05 → "지시문 2개(설명 없음·있음)에서 유지"로 적는다. 하나라도 아니면 그대로 적는다.

## 예측(확률; 실행 전 고정)
- 세 입력 모두 ±12 안(효과 없음): 70%.
- 목록·잘라낸 표 둘 다 +12 이상(채택): 10%.
- 어느 입력 −12 이하(해침): 15%.
- 설명 있음 아래 잘라낸 표 > LangChain 세 실행 모두 p<.05: 80%.
- LangChain 청크 변화 ±12 안: 85%(문장이 청크에는 해당 없음).
