석사 학위논문 연구 코드. 작업 프로젝트는 **[`rag-agent/`](rag-agent/)** 이다.

표의 데이터셀에 행·열 계층 헤더와 표 제목을 붙여 색인하고, 질문에 필요한 셀을 검색해 같은 리더에 전달하는 방법을 연구한다. 현재 비교는 **공통 검색기·리더 아래의 색인 표현 적응 실험**이다. TableRAG 등 원본 전체 시스템을 재현해 이겼다는 주장이 아니다.

> 검증 표의 MT2Net 행은 그 결정 이전의 기록이며 새 비교에 인용하지 않는다. 관련 코드·결과는

## 현재 검증 결과 — 2026-09-12

최신 다섯 표현의 검색 정확도, 답변 EM, 두 지표의 차이는 [검증 표](rag-agent/results/five_representations_20260912/VERIFIED_TABLES.md)와 [간극 감사](rag-agent/results/five_representations_20260912/GAP_REPORT.md)를 기준으로 읽는다. [선택 매니페스트](rag-agent/analysis/comparison_manifest.five.v2.json)가 원본 결과 파일을 지정한다. 과거 실행 수치를 새 표에 혼합하지 않는다.

본 방법의 현재 단일 셀 조회 결과는 검색 **906/991=.9142**, 답변 **701/991=.7074**다. 과거 자유 생성 실행의 .7164와 현재 neutral 프롬프트 실행은 다른 조건이다. 발표 슬라이드의 .7225는 대응하는 원본 결과 출처를 확인하지 못했다. 점수 목표에 맞춰 정답 판정을 바꾸지 않았다.

비교 표현은 다음과 같다.

| 표현 | 구현 범위 |
|---|---|
| 본 방법 S3c | 셀 값 + 전체 행·열 헤더 경로 + 표 제목 |
| 자체 행 보존 Markdown 청킹 | 1,000자 중단 기준, 행 보존·헤더 반복. LangChain 기본 청킹이 아님 |
| MT2Net 착안 셀 문장 | 계층 경로의 문장화. 표 제목, 원본 학습 검색기·유형 분류·추론 모듈 미포함 |
| Huawei 착안 문자 청킹 | native RecursiveCharacterTextSplitter 1,000자/200자 중첩. 원본 전체 TableRAG 파이프라인 미포함 |
| RowCol HiTab 적응 | 행·열 검색 교집합을 Markdown으로 전달. 기본 leaf 헤더에는 상위 경로 정보 손실이 있음 |

RowCol의 정보 손실을 숨기지 않는다. 같은 검색 셀에 전체 헤더 경로를 복원한 [별도 사후 진단](rag-agent/results/slide_audit_20260912/PATH_DIAGNOSTIC_VERDICT.md)에서 EM은 **.3290→.4289**로 올랐다. 이 진단은 정보와 입력 길이가 함께 바뀐 처치이며, 검색 성공률 .5126은 그대로다. 새 원본 시스템 재현 결과로 부르지 않는다.

## 지표와 비교 조건

주지표는 HiTab test 단일 셀 조회 **991문항**이다. 전체 1,584문항 중 1,581문항을 채점하고 제외 3건의 사유를 공개한다. 데이터셀 전체·다중조회·산술·헤더답은 모집단을 구분해 보고한다.

- **검색 정확도:** 실제 전달한 근거에 정답 셀 좌표가 포함됐는지 문항별로 판정한다. 좌표 포함이 해석에 필요한 헤더 정보 보존까지 보장하지는 않는다.
- **답변 EM:** 저장된 동일 문맥에서 Qwen2.5-7B-Instruct 4bit가 생성한 답을 같은 `hitab_exact_match_text` 함수로 채점한다. HiTab 수치 비교 허용오차 1e-5와 이 저장소의 다중값 텍스트 어댑터를 사용한다. 원본 공식 평가와 모든 세부 조건이 같다고 주장하지 않는다.
- **검색−EM:** `(검색 성공·답변 오답 − 검색 실패·답변 정답)/n`이다. 각 표현이 성공한 문항의 구성, 전달 정보, 방해 셀과 문맥 크기가 달라 간극도 다를 수 있다. 공통 검색 성공 문항의 결과를 함께 보고하되 부분집합 결과를 전체 우열로 일반화하지 않는다.

검색기는 BGE-base-en-v1.5와 BM25, alpha=.7이다. 모델 revision·데이터·프롬프트·seed·생성 조건·문맥 hash를 검증한다. 셀 예산 20은 **마지막 검색 단위를 통째로 넣은 뒤 멈추는 규칙**으로, 모든 표현에 정확히 20셀을 제공한 실험이 아니다. 표현별 실제 셀 수와 입력 토큰, 임베딩 절단 건수는 검증 표에 공개한다.

## 연구 해석의 한계

현재 재측정은 학습 없이 test만 사용한다. test 결과를 본 뒤 설계한 감사와 진단이므로 새로운 독립 확증 실험이 아니다. 실행 전 조건을 고정해도 반복적인 test 관찰에 따른 선택 편향이 사라지지는 않는다.

정답 셀만 제공한 본 방법의 gold 문맥 진단은 **941/991=.9495**다. 검색 성공 문항에 gold 예측, 실패 문항에 검색 문맥 예측을 고르는 오프라인 합성은 **.8769**다. 둘 다 진단값이며 수학적 상한이나 실제 배포 가능한 선별기의 성능이 아니다. 이 값만으로 문맥 개입의 개선 가능성을 단정하거나 리더 교체만 남았다고 결론 내리지 않는다.

자동 채점 재검산은 완료했지만 **독립적인 사람 의미 판정은 미실시**다. 사람 검수용 익명 예측 목록을 준비했으며 자동 EM과 구분한다. 일부 방법에만 관대한 채점 규칙을 적용하지 않는다.
